# A+

- Year: 1988
- Designer(s): Arthur Whitney, Morgan Stanley
- Paradigm(s): array, functional
- Family: numeric-scientific

## Problem It Aimed to Solve

A+ was developed to replace APL, which had been used internally at the investment bank Morgan Stanley. APL was powerful for array-oriented numerical processing, but it was not well suited to interactive application development or building graphical user interfaces. A+ therefore aimed to retain the concise array operations inherited from APL while incorporating GUI components as a language feature, providing an environment for quickly developing and running financial applications. A defining characteristic is that it was designed with the expectation of actual use in the development of the company's high-speed trading systems and analysis tools.

## Features

- Adopts array-oriented operators inherited from APL, allowing bulk operations over entire vectors and matrices to be described without writing loops
- In a functional style, expresses data transformations concisely through combinations of operators
- Comes with built-in graphical user interface construction features, supporting the development of interactive financial applications
- An interpreter-based design enables fast interactive execution, suited to trial-and-error numerical analysis workflows
- Uses ASCII-based notation, reducing reliance on the special symbols distinctive to APL

## Current Status

It is positioned as niche (a language used in a specific field). An open-source version has also been released, but use remains limited to a small group of enthusiasts and parts of the financial sector.
