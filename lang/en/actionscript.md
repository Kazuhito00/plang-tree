# ActionScript

- Year: 1998
- Designer(s): Macromedia
- Paradigm(s): object-oriented, event-driven
- Family: scripting

## Problem It Aimed to Solve

In the late 1990s, Macromedia's Flash had become popular as a vector animation tool, but it initially offered only simple timeline playback control and could not create games or interactive advertisements that responded to user actions. On the web, JavaScript was already achieving dynamic behavior, and Macromedia likewise needed to build a programmable mechanism into Flash. Building on the syntax and concepts of the then-spreading JavaScript, ActionScript was designed as a scripting language that could manipulate Flash movie clips and buttons.

## Features

- Has an ECMAScript-based syntax similar to JavaScript
- Can directly manipulate Flash's timeline, movie clips, buttons, and other display objects
- As versions progressed, it was substantially strengthened into a class-based object-oriented language (ActionScript 2.0/3.0)
- Its event-driven model makes it easy to write handlers for user actions such as clicks and key input
- Ran on Flash Player and was widely used for game development and rich internet applications

## Current Status

With the end of support for Flash Player itself in 2020 by Adobe (which had acquired Macromedia), ActionScript has become, in effect, a "historical" language that is no longer used. HTML5/CSS- and JavaScript-based technologies have taken over the roles that Flash content used to play.
