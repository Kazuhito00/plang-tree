# Alice

- Year: 1999
- Designer(s): Randy Pausch and others (CMU)
- Paradigm(s): educational, visual, object-oriented
- Family: educational-visual

## Problem It Aimed to Solve

Object-oriented programming deals with abstract concepts such as classes, methods, and instances, which made it difficult to approach, especially for programming beginners and for women and others less familiar with traditional CS education.

Randy Pausch and others at Carnegie Mellon University extended the Logo-like idea of learning by moving a character around, and developed Alice as an environment where learners could naturally absorb the concepts of objects and method calls while having fun, through the experience of moving 3D animated characters with drag-and-drop commands.

## Features

- Animations are created by manipulating 3D characters and objects with drag-and-drop blocks
- Internally, these operations correspond to object-oriented concepts of classes, methods, and instances
- Adopts a visual program-building method in which syntax errors cannot occur
- Lets learners pick up the basics of programming while having fun through animation and story creation
- Drag-and-drop operations directly correspond to underlying Java-like code, serving as a bridge to learning later languages
- Mainly introduced in introductory university and high-school CS education, and reported to be effective at reducing dropout rates among beginners

## Languages It Influenced

Its direct influence on later languages appears to be limited.


## Current Status

Alice continues to be used today in introductory university lectures and elsewhere as an educational environment for learning object-oriented concepts through 3D animation creation.

It maintains a unique position in programming education as teaching material for the stage before transitioning to text-based languages.

## Hello World

Because Alice is a visual language in which methods are assembled onto objects via drag and drop, the steps below are shown as pseudo-code representing the operations rather than as text code.

```
[Place one 3D character (object) in the world]
[Drag and drop the "say" method belonging to that object into the event area in the editor]
[Enter "Hello, World!" as the method's argument]
[Press the Run button, and the character says "Hello, World!" in a speech bubble]
```
