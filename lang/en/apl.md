# APL

- Year: 1962
- Designer(s): Kenneth Iverson
- Paradigm(s): array, functional
- Family: numeric-scientific

## Problem It Aimed to Solve

While teaching mathematical notation at Harvard University, Kenneth Iverson was dissatisfied that existing programming languages required writing multiple layers of explicit loops to express array operations such as vectors and matrices, making the code verbose. He took the original array notation he had devised for teaching and studying mathematical notation and developed it further into a language that could actually be executed on a computer.

By using dedicated symbols including Greek letters, operations such as matrix transposition, convolution, and reduction could be expressed in one or two characters, allowing vectors and matrices to be manipulated concisely in bulk without writing loops. This notation was implemented on IBM systems and was heavily used in fields that performed large amounts of numerical computation, such as finance and insurance.

## Features

- Uses a unique symbol system (requiring a dedicated APL keyboard or special fonts)
- Operations on entire arrays can be written with a single symbol
- Has a distinctive evaluation order faithful to mathematical notation, such as right-to-left evaluation
- Designed around interactive trial and error within a processing environment (workspace)
- Produces extremely concise code, though its low readability is often pointed out
- Known for an extremely dense programming style in which "one algorithm is written in one line"

## Current Status

APL is currently positioned as a language for niche uses (status: niche). As the originator of array programming using unique symbols, it gave rise to successor languages such as J and K.

Having opened up the field of array-oriented programming itself, it continues to retain a certain degree of support within specialist communities in numerical computing and finance.

## Hello World

In APL, evaluating a string literal itself displays its value, so this alone is a complete program.

```apl
'Hello, world!'
```
