# AppleScript

- Year: 1993
- Designer(s): Apple
- Paradigm(s): scripting
- Family: scripting

## Problem It Aimed to Solve

In the early 1990s, Macintosh was gaining a mechanism for "inter-application communication" that let multiple applications work together, but making use of it required specialized programming knowledge. Apple wanted to let ordinary users and power users who were not programmers build automation workflows spanning multiple applications — tasks commonly done in daily work, such as "open this file with this app, do that operation, then save it" — using a description close to natural English sentences. This led to the development of AppleScript, a scripting language with a natural-language-like syntax that makes heavy use of verbs and prepositions.

## Features

- Has a natural-language-like syntax close to English sentences (e.g. "tell application ... to ...")
- Specialized for operating and coordinating multiple applications on the Mac across each other
- Built on top of Apple Events (the mechanism for inter-application communication)
- Can be recorded, edited, and run through the Script Editor GUI tool
- Also integrated with macOS automation frameworks (such as Automator)

## Languages It Influenced

## Current Status

It is still bundled with macOS today and continues to be used for automating apps on the Mac, making it a "niche" language. In recent years it has increasingly been used alongside the more general-purpose JavaScript for Automation (JXA), but it retains its position as the representative language of macOS automation.
