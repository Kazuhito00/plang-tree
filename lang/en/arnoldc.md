# ArnoldC

- Year: 2012
- Designer(s): Lauri Hartikka
- Paradigm(s): esoteric, procedural
- Family: esoteric

## Problem It Aimed to Solve

ArnoldC was created as a joke that combined fandom with programming, expressing a program's control structures (if statements, loops, function definitions) entirely through famous lines from actor Arnold Schwarzenegger's movies. "I'll be back" represents the end of a loop, and "GET TO THE CHOPPER" represents the start of a function, and so on: the goal itself was to dutifully map famous movie lines onto syntactic elements, with no intention from the outset of solving any practical programming problem.

## Features

- All elements of ordinary programming syntax — variable declarations, conditional branches, loops, function definitions — are mapped to famous movie lines
- Lines such as "IT'S SHOWTIME" and "YOU HAVE BEEN TERMINATED" are used to mark the start and end of a program
- Because the style is to write the lines verbatim in all capitals, the code looks like a collection of famous movie scenes
- Figurative command names such as "GET UP" and "GET DOWN" are used even for adding to and subtracting from variables
- Despite its striking appearance, it actually has a full set of control structures as a procedural language

## Current Status

Positioned as an esoteric language, it is not used for practical purposes. As a joke language that even movie fans can appreciate, it is still frequently cited today as an introduction to esoteric languages or as a joke in presentation titles.

## Hello World

This is ArnoldC's standard Hello World program: the program begins with "IT'S SHOWTIME," outputs a string with "TALK TO THE HAND," and ends with "YOU HAVE BEEN TERMINATED."

```
IT'S SHOWTIME
TALK TO THE HAND "Hello, world!"
YOU HAVE BEEN TERMINATED
```
