# Clarion

- Year: 1986
- Designer(s): Bruce Barrington
- Paradigm(s): procedural, object-oriented
- Family: domain-specific

## Problem It Aimed to Solve

In the mid-1980s, developing database business applications on the IBM PC with the low-level languages of the time made screen design and memory management cumbersome, resulting in low development efficiency. Bruce Barrington aimed to integrate a compact, expressive language specification with a screen designer that made full use of the PC's memory-mapped screen. Influenced by Pascal-style structured programming, Clarion simplified database application development by providing an integrated 4GL development environment. It continues to be maintained by SoftVelocity today and remains in use in a niche segment of business systems.

## Features

- Adopts a structured programming style derived from Pascal, enabling highly readable code
- An IDE integrating a screen designer with code generation allows database input and output screens to be built quickly
- As a 4GL, it provides declarative syntax that concisely expresses database access
- Object-oriented features were added later, enabling code reuse through templates
- Its design directly leverages the PC's memory-mapped screen display, efficiently exploiting the hardware performance of its era
