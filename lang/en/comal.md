# COMAL

- Year: 1975
- Designer(s): Børge R. Christensen, Benedict Løfstedt
- Paradigm(s): procedural
- Family: origin

## Problem It Aimed to Solve

In the 1970s, BASIC, widely used in education at the time, was interactive and easy to learn, but tended to produce unstructured code centered on GOTO statements — the kind of code known as "spaghetti code." Danish mathematics teacher Børge Christensen designed COMAL as a language combining the ease of BASIC with the benefits of Pascal's structured programming. By introducing block structures such as `IF...THEN...ENDIF` and `PROC...ENDPROC`, it made it possible to write readable code without relying on line numbers or GOTO. It spread through schools in the Nordic countries and the UK as an educational language of the 8-bit home computer era.

## Features

- Has Pascal-derived block structures such as `IF...THEN...ENDIF`, `WHILE...ENDWHILE`, and `PROC...ENDPROC`
- Lets programmers write readable code in a structured programming style without relying on line numbers or GOTO statements
- Provides an interactive execution environment like BASIC, letting beginners check results right away as they learn
- Allows procedures (`PROC`) and functions (`FUNC`) with local variables to be defined, enabling modular programs
- Was ported to 8-bit home computers (BBC Micro, Commodore, and others), which helped it spread through schools

## Current Status

COMAL is still positioned today as an educational language, continuing to be used in some educational settings and enthusiast communities as material for teaching the fundamentals of structured programming. It is almost never newly adopted for commercial or industrial use, but is historically valued as an educational language that bridged BASIC and structured programming.

## Hello World

In COMAL, the `PRINT` statement is used to print a string.

```comal
PRINT "Hello, world!"
```
