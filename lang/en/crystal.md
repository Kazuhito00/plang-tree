# Crystal

- Year: 2014
- Designer(s): Ary Borenszweig and others
- Paradigm(s): object-oriented
- Family: concurrent-actor

## Problem It Aimed to Solve

Ruby was beloved by programmers for its readable, easy-to-write syntax, but being a dynamically typed interpreted language, its execution speed lagged far behind compiled languages like C. Ary Borenszweig and others developed Crystal to preserve Ruby-like natural, concise syntax as much as possible, while using static typing and type inference to catch many errors at compile time, and ultimately compiling to native code to achieve execution speed comparable to C.

## Features

- Has syntax closely resembling Ruby's readable style, yet is compiled as a statically typed language
- Powerful type inference lets it benefit from static type checking in most cases without explicit type annotations
- Compiles to native binaries using LLVM, achieving execution speed close to C
- Supports lightweight concurrency via fibers
- Allows compile-time metaprogramming through macros

## Current Status

Crystal is a niche language with a clear concept—"write like Ruby, run like C"—and is supported by a community of developers who prioritize performance, though it has not achieved mainstream adoption.
