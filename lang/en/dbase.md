# dBase

- Year: 1979
- Designer(s): Wayne Ratliff
- Paradigm(s): procedural, query
- Family: domain-specific

## Problem It Aimed to Solve

In the late 1970s, when personal computers were just beginning to appear, database management was a technology for specialists working on mainframes or minicomputers, and it was difficult for ordinary users to build and search simple databases such as address books or inventory lists on their own.

Wayne Ratliff, an engineer at JPL (the Jet Propulsion Laboratory), developed a data-management program called Vulcan as a hobby project and expanded it into dBase, which allowed users to register, search, and aggregate data simply by entering commands, without requiring specialized knowledge. It was then commercialized by Ashton-Tate.

## Features

- Stores tabular data as files (.dbf) and manipulates them with interactive commands
- Has simple search and sort commands resembling SQL
- Database processing can be described in both an interactive mode and through programs (command files)
- Ran on the personal computers of the time (CP/M, and later MS-DOS), making it accessible even to non-specialists
- The ".dbf" format became widely adopted as an industry standard, giving rise to many compatible products
- Had a full set of functions needed for business application development, including report generation and menu screen creation

## Current Status

dBase is now a historical language with almost no new practical use, but as a pioneer of database management software for personal computers, it left a great influence on subsequent compatible products and the culture of business application development. The ".dbf" file format continued to be used for a long time as a data exchange format with other software, even after dBase itself declined.
