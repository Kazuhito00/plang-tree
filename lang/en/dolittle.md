# Dolittle (ドリトル)

- Year: 2000
- Designer(s): Susumu Kanemune, Yasushi Kuno
- Paradigm(s): object-oriented, educational, visual
- Family: educational-visual

## Problem It Aimed to Solve

Around the year 2000, computing education in Japanese elementary and junior high schools called for teaching materials that would let students learn the fundamentals of programming without stumbling over English-based syntax. Susumu Kanemune (currently a professor at Osaka Electro-Communication University) and Yasushi Kuno believed that a language allowing objects to be manipulated in Japanese word order (subject-object-predicate) would let children naturally encounter the ideas of object orientation and turtle graphics, and they designed Dolittle with this in mind. Its name derives both from "do little" (a play on doing a bit of programming) and from Hugh Lofting's novel character Doctor Dolittle.

## Features

- Commands can be written in Japanese subject-object-predicate word order
- Turtle graphics functionality that draws shapes by manipulating a cursor called a "turtle"
- Objects are handled in a prototype-based manner, letting learners naturally absorb object-oriented ideas by combining and manipulating pre-made parts
- Automatic collision detection when shapes are moved
- Also includes a music feature called "Stoton notation," which allows composing using solfège (do-re-mi) note names
- Distributed as freeware and widely used as teaching material in elementary and junior high school computing education and in programming schools

## Current Status

As a Japanese-language educational object-oriented language, it continues to be used today as programming teaching material in primary and secondary education.

## Hello World

Dolittle has no dedicated console output command; instead, a string is displayed on screen by creating a GUI part called a "label."

```
ラベル1＝ラベル！"Hello, World!"　作る。
```
