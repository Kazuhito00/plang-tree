# F#

- Year: 2005
- Designer(s): Don Syme
- Paradigm(s): functional, object-oriented
- Family: ml-functional

## Problem It Aimed to Solve

In the early 2000s, Don Syme at Microsoft Research wanted to bring expressive functional programming in the style of OCaml to .NET, the mainstream Windows development platform. At the time, .NET developers were limited to procedural, object-oriented languages such as C# and Visual Basic, and could not benefit from a functional style built on concise type inference, pattern matching, and immutable data. F# was therefore developed as a language grounded in OCaml's syntax and semantics, while being fully interoperable with the .NET Common Language Runtime (CLR) and its existing libraries.

## Features

- Hindley-Milner type inference and concise syntax inherited from OCaml
- Seamless interoperability with .NET class libraries and code written in C#
- Functional tools such as discriminated unions (algebraic data types), pattern matching, and record types
- Practically oriented extensions of its own, such as asynchronous workflows and units of measure
- Also has object-oriented features, allowing natural integration into existing .NET class hierarchies

## Current Status

As one of the official languages of the .NET ecosystem, F# continues to see practical use in areas such as analytics systems in the financial industry and data science. It stands as a leading example of putting OCaml's academic type system to commercial use on a mainstream platform.
