# FreeBASIC

- Year: 2004
- Designer(s): Andre Victor T. Vicentini
- Paradigm(s): procedural, object-oriented
- Family: origin

## Problem It Aimed to Solve

With the end of DOS, the enormous body of assets written in Microsoft QuickBASIC and the familiar BASIC syntax were becoming unusable as-is. FreeBASIC arose from the motivation to keep this legacy and knowledge usable by providing a free, open-source successor implementation. It also aimed to let developers keep using familiar BASIC syntax largely unchanged while generating native code on modern operating systems comparable to that produced by C.

## Features

- Maintains high syntactic compatibility with QuickBASIC while generating native executable files on modern operating systems (Windows, Linux, and others)
- Supports pointer manipulation and object-oriented programming in addition to procedural programming
- Allows writing inline assembly and linking with C libraries, supporting low-level control as well
- Can switch between multiple compilation dialects (QB-compatible mode, FB mode, Deprecated mode, and others)
- Provided as open source and free of charge, and used as a migration path for BASIC assets from the DOS era

## Current Status

It is positioned as a niche language used in a specific field. It maintains a devoted user community, both for the hobbyist preservation of retro BASIC programming and for practical uses such as game development.
