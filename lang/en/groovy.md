# Groovy

- Year: 2003
- Designer(s): James Strachan and others
- Paradigm(s): object-oriented, scripting
- Family: smalltalk-oop

## Problem It Aimed to Solve

In the early 2000s, Java was firmly established as the standard language for enterprise systems on the JVM, but its static, verbose syntax lacked scripting-style agility. James Strachan and others wanted to bring in dynamic typing and concise syntax in the style of Ruby while fully leveraging Java's vast library assets and the JVM execution platform, in order to raise productivity in day-to-day development. The starting point was a language that was easier to write while remaining seamlessly interoperable with existing Java code.

## Features

- Highly compatible with Java, able to call existing Java class libraries directly
- A flexible type system that allows dynamic typing together with optional static typing
- Concise expressive power borrowed from Ruby and other scripting languages, such as closures and builder syntax
- Designed to make it easy to write DSLs (domain-specific languages) in Groovy code itself
- Widely adopted in practice as the standard scripting language of the build tool Gradle

## Current Status

It is currently positioned as a niche language, with limited adoption as a general-purpose scripting language. On the other hand, it remains widely used as the scripting language for Gradle build scripts, holding a place within the JVM ecosystem.
