# GW-BASIC

- Year: 1983
- Designer(s): Microsoft
- Paradigm(s): procedural
- Family: origin

## Problem It Aimed to Solve

Early IBM PCs came with Cassette BASIC burned into ROM or the disk-based BASICA (made by IBM), but these depended on ROM built into IBM hardware and could not run as-is on third-party PC/AT compatible machines. Microsoft developed GW-BASIC as an independent BASIC implementation that did not depend on ROM and worked entirely from disk, maintaining high compatibility with existing BASICA programs while making it possible to distribute it widely across the PC-DOS/MS-DOS environment as a whole.

## Features

- Followed the classic BASIC grammar centered on line numbers and GOTO/GOSUB statements
- An independent interpreter that did not depend on ROM and ran solely from floppy disk
- High compatibility with IBM Cassette BASIC/BASICA, allowing existing program assets to run as-is
- Featured numerous instructions for directly controlling the PC hardware of the time, such as graphics and sound commands
- Bundled with many PC/AT compatible manufacturers, becoming widely popular as an introductory language for PC users in the 1980s

## Current Status

GW-BASIC is now positioned as a historical language (status: historical) with almost no practical use today. However, the role it played during the PC boom of the 1980s was significant, and it occupies an important place in the history of programming education as the starting point of a lineage leading to QuickBASIC, QBasic, and Visual Basic.
