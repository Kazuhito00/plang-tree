# Himawari (ひまわり)

- Year: 2001
- Designer(s): Kujira Hikoutsukue
- Paradigm(s): scripting, procedural
- Family: scripting

## Problem It Aimed to Solve

Around 2000, English-based syntax was a major barrier to learning for Japanese speakers, especially programming beginners. Kujira Hikoutsukue thought that this barrier could be removed if programs could be written using the grammar of the Japanese language as-is. Himawari was developed as a pioneering attempt to demonstrate that practical programs could be written using a Japanese-language processing system alone, and it was implemented in Delphi (Object Pascal).

## Features

- An interpreted language in which commands and control structures can be written directly using Japanese particles and word order
- Natural Japanese expressions such as "~naraba" (if ~) and "~suru" (do ~) are mapped onto control structures
- Mainly intended for Windows GUI applications and text processing
- Its execution speed was relatively stable compared with other Japanese programming languages, but it also had issues such as the need for word segmentation (wakachigaki) and unnatural command phrasing

## Current Status

Development stopped after the release of Ver. 1.94 in 2008, and it is now positioned as a historical language. Its design philosophy has been carried forward into its successor language, Nadeshiko.
