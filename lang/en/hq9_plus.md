# HQ9+

- Year: 2001
- Designer(s): Cliff L. Biffle
- Paradigm(s): procedural
- Family: esoteric

## Problem It Aimed to Solve

HQ9+ is a joke language created to parody the standard exercises common in learning many programming languages: printing "Hello, World!", writing a quine that outputs its own source code, and printing the lyrics of "99 Bottles of Beer" with its recursive repetition. It has only four instructions—H, Q, 9, and +—and cannot be used to write practical programs, though it is sometimes used as a quick check of whether these standard exercises can be implemented when someone creates a new esoteric language.

## Features

- Has only four instructions: H (prints "Hello, world!"), Q (a quine that prints its own source code), 9 (prints the lyrics of "99 Bottles of Beer"), and + (increments an accumulator)
- Has no variables or control structures whatsoever; each instruction is interpreted and executed exactly once, in the order it appears in the program
- Since there is no way to output the accumulator's value, the + instruction has effectively no observable effect
- Not Turing complete, having abandoned from the outset any intention of writing practical programs
- Sometimes referenced as a simple benchmark for whether the "standard three exercises" can be implemented when a new esoteric language is created

## Current Status

HQ9+ is positioned as a niche esoteric language and is not intended for practical use. Owing to its small instruction count and joke nature, it continues to be referenced within the esoteric-language community as a point of reference for designing and comparing later languages.
