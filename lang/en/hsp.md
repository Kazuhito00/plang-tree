# HSP (Hot Soup Processor)

- Year: 1996
- Designer(s): Onitama
- Paradigm(s): procedural, scripting
- Family: scripting

## Problem It Aimed to Solve

In the mid-1990s, following its predecessor Light SOUP Processor (LSP), which had been developed for the PC-9800 series, Onitama wanted to let programming beginners and hobbyists who wished to make games or tools write programs with the ease of BASIC, but suited to the Windows environment of the time. Development began in 1995, and it was released as freeware in 1996.

## Features

- Its notation is inspired by the BASIC language originating at Dartmouth College, but it has its own independent grammar with no compatibility
- Combines the ease of not needing variable type declarations with direct access to the Windows API
- Works produced with it can be distributed standalone by converting them into executable files (with the .ax extension)
- Widely used in the doujin (fan-made) game and hobby programming community, with many Japanese-language reference books published
- Has been continuously developed and updated for nearly 30 years

## Current Status

It is a domestically developed (Japanese) hobby-oriented language that has long enjoyed high recognition in the game development and doujin software community, and it continues to be developed today as HSP3.
