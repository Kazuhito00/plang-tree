# J

- Year: 1990
- Designer(s): Kenneth Iverson, Roger Hui
- Paradigm(s): array, functional
- Family: numeric-scientific

## Problem It Aimed to Solve

APL's notation was mathematically powerful, but it had the practical drawback of requiring special keyboards and fonts to input its dedicated symbols (such as ∇ and ⍴), making it difficult to use on ordinary terminals or in ASCII environments. Kenneth Iverson, APL's own creator, together with Roger Hui, wanted to create a successor language that could be written using only a standard ASCII keyboard without sacrificing the expressive power of array programming. By replacing special symbols with combinations of characters (compound operators such as `/.`, for example), it was designed as a language that would be easy to print, distribute, and share as text files.

## Features

- Emphasizes tacit programming (function composition), inherited from APL, for operating on entire arrays at once
- Expresses operators using combinations of standard ASCII characters rather than special symbols
- High conciseness that allows complex array operations to be expressed with very little code
- Places functional ideas (function composition and forks) at the core of the language
- Used in both commercial and academic settings, though its distinctive notation makes it difficult to learn

## Current Status

J is positioned as a niche language (status: niche), and as a successor array language that re-expressed APL using only ASCII characters, it continues to be used firmly by some specialists in fields such as numerical computing and finance.
