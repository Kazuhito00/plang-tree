# Java

- Year: 1995
- Designer(s): James Gosling
- Paradigm(s): object-oriented, concurrent
- Family: jvm-dotnet

## Problem It Aimed to Solve

Java originated in an in-house effort called the "Green Project," conceived as a language for controlling home appliances and embedded devices, where the same binary would run on any CPU architecture (its original name was Oak). However, the interactive television market it targeted never took off, and the development team redirected the technology toward the rapidly growing World Wide Web instead. Distributing native applications written in C or C++ to an unspecified number of browser environments carried risks of crashes and security vulnerabilities and was not realistic, so a safe, portable language that ran on a virtual machine was needed.

## Features

- Bytecode execution on the Java Virtual Machine (JVM), realizing "Write Once, Run Anywhere"
- A safety-focused design that eliminates pointer arithmetic and provides automatic memory management (garbage collection)
- Class-based single-inheritance object orientation combined with multiple implementation via interfaces
- An extremely rich standard library that supports an ecosystem underpinning enterprise system development
- A history of expanding application range, from embedded languages to web applets to large-scale server-side systems

## Current Status

Java remains one of the de facto standard languages for enterprise system development today, and it is widely in active use for Android app development and enterprise backend systems. The JVM execution platform continues to serve as the foundation for numerous later languages (Kotlin, Scala, Clojure, and others), and the language itself continues to expand its features through regular version updates.
