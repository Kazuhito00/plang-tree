# JavaScript

- Year: 1995
- Designer(s): Brendan Eich
- Paradigm(s): scripting, functional, object-oriented, event-driven
- Family: scripting

## Problem It Aimed to Solve

In 1995, in the middle of the browser wars, Netscape urgently needed a lightweight language that could give static HTML pages simple dynamic behavior, such as form validation. Under the extremely tight constraint of having to design and implement this language in just ten days, Brendan Eich combined Scheme's functional ideas with Self's prototype-based object model, and gave it a Java-like syntax to help drive its adoption. This rushed origin also led to the quirks in the language specification that continued to be pointed out for years afterward.

## Features

- A prototype-based object model (class syntax has also been available for use since ES6)
- A functional aspect that treats functions as first-class values
- Designed around DOM manipulation and event-driven programming in the browser
- With the advent of Node.js, it also expanded into server-side development and CLI tools
- The flexibility of dynamic typing coexists with unexpected behavior arising from type coercion

## Current Status

It is still "active" today, its status as the standard language of the browser remains unshaken, and through Node.js it has also spread widely into server-side development and various toolchains. Despite being a language born in ten days, it has become one of the most executed programming languages in the world.
