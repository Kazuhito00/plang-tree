# JOSS

- Year: 1963
- Designer(s): Cliff Shaw
- Paradigm(s): procedural
- Family: origin

## Problem It Aimed to Solve

At RAND Corporation in 1963, there was a demand for mathematicians and analysts to be able to solve problems by conversing directly with a computer, without going through a dedicated programmer. JOSS (JOHNNIAC Open Shop System) aimed for a mechanism, in a time-sharing environment, that would let multiple users use the computer conversationally at the same time, in a way that felt natural even without training. At a time when batch processing was the norm, an interactive response model in which computation results came back immediately after user input was groundbreaking, and it became a forerunner of later time-sharing systems and interactive languages. It is also known for having been created by Cliff Shaw, who also designed IPL.

## Features

- Has an interactive execution model in which commands are entered conversationally and results are returned immediately
- Designed for use by multiple users simultaneously in a time-sharing environment
- Adopts plain grammar so that non-specialist programmers, such as mathematicians and analysts, can use it
- Structures programs by numbering each statement, in a style characteristic of early interactive languages
- Designed on the premise of running on dedicated JOHNNIAC hardware

## Current Status

It is positioned as historical (a language whose historical role has ended). JOSS itself is no longer used, but it holds a place in the history of computer science as an important early language that pioneered the idea of interactive computer use.
