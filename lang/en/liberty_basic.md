# Liberty BASIC

- Year: 1992
- Designer(s): Carl Gundel
- Paradigm(s): procedural, event-driven
- Family: origin

## Problem It Aimed to Solve

There was a need for programming beginners and hobbyists to be able to easily create GUI applications that ran on Windows, without having to worry about complex API calls. Liberty BASIC aimed to provide an environment for building practical Windows applications with a low learning cost, by making it possible to handle GUI elements such as windows and buttons using nothing but familiar, simple BASIC syntax.

## Features

- Handles GUI elements such as windows, buttons, and text boxes while keeping simple BASIC syntax
- Lets developers build GUI applications using only high-level instructions, without needing to know the details of the Windows API
- Runs as an interpreter, so code can be run and checked immediately after writing
- An event-driven programming model makes it easy to write processing that responds to user actions
- Includes a feature for converting programs into executable (exe) files, allowing created programs to be distributed

It is positioned as a niche language used in a specific field. It maintains a loyal user base as an accessible tool for Windows GUI development aimed at programming beginners and hobbyists.
