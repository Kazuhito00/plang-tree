# Lua

- Year: 1993
- Designer(s): Roberto Ierusalimschy and others
- Paradigm(s): scripting, procedural
- Family: scripting

## Problem It Aimed to Solve

In the early 1990s, high tariffs and restrictions on imports made it difficult to obtain foreign commercial software and dedicated data-processing tools in Brazil. Researchers at the Pontifical Catholic University of Rio de Janeiro, who were working on a data-processing project for Petrobras (the Brazilian state oil company), needed a lightweight configuration and extension language that could be developed and maintained domestically, as a replacement for existing expensive commercial tools. It was designed to be easily embedded in C-based host applications with extremely low runtime overhead.

## Features

- Represents arrays, objects, and modules all through a single data structure called a table (an associative array)
- Highly interoperable with C, and an extremely lightweight interpreter suited for embedding
- Supports cooperative multitasking via coroutines as a standard feature
- Widely adopted as the scripting language of game engines (Roblox, World of Warcraft, etc.)
- Simple grammar and a compact implementation size

## Current Status

Lua remains "active" today, and continues to stand as the archetypal embedded scripting language, especially in game development. Born in Brazil out of a need for lightness and ease of embedding, it has become a language used in game engines and embedded devices around the world.
