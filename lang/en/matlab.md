# MATLAB

- Year: 1984
- Designer(s): Cleve Moler
- Paradigm(s): array, procedural
- Family: numeric-scientific

## Problem It Aimed to Solve

In the 1970s, in university numerical analysis courses, students had to compile and link Fortran code just to use matrix computation libraries such as LINPACK and EISPACK, which got in the way before they could even get to the essence of learning matrix operations. Cleve Moler, then a faculty member at the University of New Mexico, wanted to create an environment where students could try out matrix operations interactively, simply by typing commands, without having to think about compiling. Thus was born MATLAB, short for "Matrix Laboratory," designed as an interactive environment for handling linear algebra with the ease of a calculator. It was later commercialized and grew into a standard environment for technical computing in general, including control engineering and signal processing.

## Features

- Treats matrix and array operations as the basic unit of all data
- Has a REPL-style interactive execution environment, letting users immediately check computation results and graphs
- A rich collection of toolboxes for numerical computation, signal processing, and control engineering
- Enables model-based design and simulation in conjunction with Simulink
- Commercial software, widely adopted by technical departments at universities and companies

## Current Status

It remains an active language today (status: active), and continues to be widely used in university education and in engineering and finance practice as a commercial environment for technical computing and simulation centered on matrix operations. Even as open-source alternatives (such as Julia and Python+NumPy) rise, it retains solid demand thanks to its accumulated technical assets and rich toolboxes.
