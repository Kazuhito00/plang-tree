# Mind

- Year: 1985
- Designer(s): Katagiri Akira
- Paradigm(s): procedural, stack-based
- Family: origin

## Problem It Aimed to Solve

Forth allows fast, resource-efficient programs to be written thanks to its stack-based computational model, but its notation built from English word sequences was not intuitive for Japanese speakers. Katagiri Akira wanted to preserve Forth's powerful computational model and extensibility while making it possible to write programs in a natural notation closer to Japanese word order, creating a Japanese programming language robust enough to withstand the development of large-scale business systems such as POS systems.

## Features

- Has a stack-based execution model derived from Forth
- Instruction sequences can be written in Japanese-like word order, giving it an appearance that is easy for beginners to read
- Has provided both an interactive interpreter environment and a compiler since the MS-DOS era
- Has flexibility inherited from Forth, such as the ability to invoke the compiler from within a program via a word called "compile"
- Has developed less as an educational language and more as a language for practical, large-scale development such as POS systems

## Current Status

Among Japanese programming languages it has a long history, and it remains a niche language still used today in the field of business system development.

## Hello World

In Mind, the main procedure is defined with "メインとは" ("as the main"), and strings are output using a syntax close to Japanese word order, "〜と 表示する。" ("display ~").

```
メインとは
　「こんにちは、世界。」と　表示する。
```
