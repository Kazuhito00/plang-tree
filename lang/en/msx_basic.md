# MSX BASIC

- Year: 1983
- Designer(s): Microsoft, ASCII Corporation, Kazuhiko Nishi
- Paradigm(s): procedural
- Family: origin

## Problem It Aimed to Solve

MSX BASIC is the standard BASIC interpreter that Microsoft and ASCII Corporation developed by extending MBASIC for "MSX," a home computer standard that unified specifications across multiple manufacturers. At the time, various manufacturers were fragmenting the market with proprietary computer specifications and BASIC dialects, and the goal was to unify the standard so that software assets could be shared. Instructions were added to take advantage of MSX-standard hardware features such as graphics, music, and expansion cartridges. Because it was built into ROM and available the moment the machine powered on, it spread widely among hobbyists and in educational settings.

## Features

- An interpreter built on Microsoft's MBASIC, extended to handle MSX-standard hardware uniformly across manufacturers
- Equipped with dedicated instructions to control the graphics VDP and PSG sound chip common across all manufacturers
- Supports instructions for accessing expansion hardware connected via the cartridge slot, such as disk drives and mega-ROMs
- Bundled as standard ROM and available the moment the machine powered on, making it accessible even to hobbyists
- Has an instruction set suited to game creation, including graphics display via sprite features
- Its BASIC generation was updated in step with standard revisions such as MSX2, MSX2+, and MSX turbo R

## Current Status

With the end of MSX computer production, its role as a practical language has ended, and it is positioned as a language whose historical role is over. Today it survives through use on emulators among retro-computing enthusiasts and as a reference for historical game development.
