# Nadeshiko (なでしこ)

- Year: 2005
- Designer(s): Kujira Hikouki (クジラ飛行机)
- Paradigm(s): scripting, procedural
- Family: scripting

## Problem It Aimed to Solve

Its predecessor language, Himawari (ひまわり), was praised for its philosophy of letting programs be written in Japanese, but it had practical shortcomings such as slow execution speed, the need for word-segmented (spaced) text, and many unnatural Japanese commands. To resolve these problems, Kujira Hikouki chose not merely to improve the existing codebase but to rethink the grammar and system architecture from the design stage, building a more natural and faster Japanese programming language from scratch. The official release was published on February 17, 2005.

## Features

- Programs can be written in a natural grammar that makes use of Japanese particles, in a "~wo ~shite" ("do ~ to ~") style
- Execution speed is more than ten times faster than Himawari
- Its runtime environments have diversified, ranging from Windows desktop applications to a JavaScript version that runs in a web browser
- "Nadeshiko 3" migrated to a JavaScript implementation, running on both Node.js and in browsers
- Featured in academic journals of the Information Processing Society of Japan, and also used as teaching material for Japanese-language programming education

## Current Status

Nadeshiko is one of the best-known Japanese programming languages in Japan, and continues to be used today for educational purposes and hobbyist programming. Development is ongoing, and version 3 moved to a JavaScript-based implementation.
