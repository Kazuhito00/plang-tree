# GNU Octave

- Year: 1988
- Designer(s): John W. Eaton
- Paradigm(s): procedural, array, object-oriented
- Family: numeric-scientific

## Problem It Aimed to Solve

Octave originated from the need, in the late 1980s, for a free tool capable of performing numerical computation involving matrix and vector operations, as supplementary material for a course on chemical reactor design. At the time, commercial numerical computing software such as MATLAB was expensive, making it difficult for educational institutions and individuals to use it freely. John W. Eaton adopted a language specification highly compatible with MATLAB while developing it as free software that could be freely used and modified under the GPL. This contributed to the democratization of numerical analysis and scientific computing, and it remains widely used in academia and industry today.

## Features

- An array-oriented language design that treats matrices and vectors as fundamental data types, allowing linear algebra operations to be expressed concisely
- Highly compatible with the MATLAB language specification, allowing many MATLAB scripts to run unmodified or with only minor changes
- Free software released under the GNU General Public License (GPL), which can be freely used, modified, and redistributed
- Provides an interactive command-line interface, allowing numerical results to be checked immediately while experimenting
- Object-oriented class features were added later, enabling the implementation of more complex data structures and algorithms
