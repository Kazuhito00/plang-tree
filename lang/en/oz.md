# Oz

- Year: 1991
- Designer(s): Gert Smolka
- Paradigm(s): logic, functional, concurrent, object-oriented
- Family: logic-declarative

## Problem It Aimed to Solve

Around 1990, the world of programming languages had a variety of paradigms — logic, functional, object-oriented, and concurrent — each existing as its own independent family of languages, without an adequate framework for understanding them in a unified way. Smolka wanted to integrate these multiple paradigms into a single language without contradiction, positioning them atop a single computational model (a concurrent computation model based on constraint programming). Furthermore, Oz was strongly conscious of educational purposes as well as research, aiming to let learners systematically understand the essential differences and commonalities among various computational models through a single implementation.

## Features

- Integrates logic programming, functional programming, object orientation, and concurrent constraint programming on a single language foundation
- Builds other paradigms atop a core model of constraint programming using single-assignment variables and logic variables
- Enables natural expression of concurrent processing through lightweight threads and dataflow variables
- Was developed in conjunction with educational materials and a book ("Concepts, Techniques, and Models of Computer Programming")
- Also provides distributed programming features in an integrated manner through the Mozart Programming System implementation

## Current Status

Oz is a historical language (having completed its historical role) and is not widely used in practice today. However, its design philosophy of handling diverse paradigms atop a unified computational model continues to be referenced in programming language education and research.
