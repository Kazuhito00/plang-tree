# Pharo

- Year: 2008
- Designer(s): Stéphane Ducasse, Marcus Denker
- Paradigm(s): object-oriented
- Family: smalltalk-oop

## Problem It Aimed to Solve

Squeak was overly specialized for educational use, and as a foundation for full-scale commercial or research software development it was either overloaded with unnecessary features or had issues with stability. Pharo aimed, by cleanly forking from Squeak, to create a highly modular, open-source next-generation Smalltalk environment able to withstand modern software development practices. It is notable for stripping away the educational elements and aiming to reconstruct a pure Smalltalk environment usable by researchers and professional developers on real projects.

## Features

- A pure object-oriented language carrying on the tradition of Smalltalk-80, in which everything is treated as an object
- Has a live environment (image) that provides a development experience where the running system can be directly edited and saved
- A modularized package system that allows building a lightweight environment incorporating only the features needed
- Includes powerful reflection features and an integrated development environment with a debugger and code browser
- Reconstructed from Squeak by removing its educational elements, redesigned to suit research and industrial application

## Current Status

Pharo is an actively used language, with development and use continuing energetically in the research community and in some industrial applications. It has gained support as a venue for practicing pure object orientation and live programming.
