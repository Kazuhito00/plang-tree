# PHP

- Year: 1995
- Designer(s): Rasmus Lerdorf
- Paradigm(s): scripting, procedural, object-oriented
- Family: scripting

## Problem It Aimed to Solve

In 1994, Rasmus Lerdorf created a simple set of CGI scripts written in Perl, called "Personal Home Page Tools," to track visits to his personal homepage. Rewriting these in C while extending their functionality was the starting point of PHP, and from the beginning it had a strongly practical character — not an academic language design, but a tool for embedding code in HTML to quickly build form processing and dynamic pages. This development style of "adding features as the need arises" led to its overwhelming practicality in later Web development.

## Features

- A template-like notation that lets you embed code directly inside HTML files
- Built on the assumption of integration with a Web server, with request processing and session management as rich standard features
- A practical, "just make it work" orientation backed by a huge collection of built-in functions
- Widely adopted as the backend language for large-scale CMSes, WordPress foremost among them
- Type declarations and object-oriented features have been strengthened retroactively with each successive version

## Current Status

It remains "active" today as one of the main languages for Web server-side development, and a considerable portion of the world's websites, WordPress included, run on PHP. It is a rare example of a language that grew from a personal set of tools into one that underpins large-scale commercial services.
