# PowerBuilder

- Year: 1991
- Designer(s): Mitchell Kertzman, Dave Litwack
- Paradigm(s): object-oriented, event-driven, visual, query
- Family: domain-specific

## Problem It Aimed to Solve

From the late 1980s, as Microsoft Windows spread, demand rapidly grew for business applications with graphical user interfaces, but development methods of the time offered low productivity. Powersoft Corporation developed a rapid application development (RAD) tool centered on its own DataWindow component, which abstracted database access. This made it possible to efficiently build data input and output screens without needing to be aware of differences between database vendors. It remains widely used today in core business systems in finance, manufacturing, and government.

## Features

- A proprietary component called DataWindow allows the results of SQL queries to be declaratively mapped onto GUI screens
- Adopts an event-driven programming model, letting developers intuitively write handlers for GUI events such as button clicks
- Incorporates object-oriented concepts, treating windows and controls as objects
- Includes a visual form designer that lets screen layouts be built via drag and drop
- Has an abstraction layer supporting multiple database vendors, enabling highly portable business applications
