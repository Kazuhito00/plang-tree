# Prodel (プロデル)

- Year: 2007
- Designer(s): Yuto
- Paradigm(s): object-oriented, scripting
- Family: scripting

## Problem It Aimed to Solve

The Japanese-language programming language TTSneo had been a beloved scripting language built on Visual Basic 6.0, but as the era of .NET arrived, its underlying technology was becoming outdated. The developer known as "Yuto" wanted to rebuild, on the .NET Framework, an environment that let users develop object-oriented Windows applications while writing code in natural Japanese word order, in order to offer TTSneo users a successor language they could migrate to. A concept version was released in August 2007.

## Features

- Uses parsing based on Japanese particles, allowing programs to be written in natural Japanese word order
- Supports object-oriented programming, with a rich set of standard features such as GUI widgets and image drawing
- Runs on the .NET Framework, with Windows application development as its primary purpose
- In 2018, a browser-based execution environment called "Prodel Online," built using WebAssembly, was also released
- Continues to be updated in both stable and development versions

## Languages It Influenced

Its direct influence on later languages appears to be limited.


## Current Status

Prodel is often introduced as one of the "three major Japanese programming languages," alongside Nadeshiko and Dolittle, and remains a niche language on the .NET platform that continues to be actively developed today.
