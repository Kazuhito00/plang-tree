# PureBasic

- Year: 2000
- Designer(s): Fred (Fantaisie Software)
- Paradigm(s): procedural
- Family: origin

## Problem It Aimed to Solve

When Blitz Basic, which had been popular on the Amiga, was discontinued, there was a motivation to carry on its spirit while creating a simple, fast, native-code-generating BASIC that could also be used on new platforms such as Windows. PureBasic deliberately excluded complex concepts such as object orientation, committing purely to structured programming, aiming to be a lightweight language that was both accessible to beginners and excellent in execution speed.

## Features

- Specializes in simple structured programming and deliberately has no object-oriented features
- Compiles to native machine code, achieving high execution speed
- A cross-platform design supporting multiple platforms including Windows, Linux, and macOS
- Also supports writing inline assembly and low-level system access
- Can be learned relatively quickly even by beginners, thanks to its integrated development environment (IDE) and simple grammar

## Current Status

It is positioned as a niche language used in a specific domain. It continues to be used steadily by those in game development and utility development who want to easily create native applications.
