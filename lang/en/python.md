# Python

- Year: 1991
- Designer(s): Guido van Rossum
- Paradigm(s): object-oriented, procedural, functional
- Family: scripting

## Problem It Aimed to Solve

Guido van Rossum had worked on the educational language ABC, which was easy to read but lacked practical extensibility such as modularity and exception handling. In the late 1980s, while doing systems administration and tool development at a research institute, he came to feel the need for a language that kept simple syntax approachable to beginners while offering enough general-purpose power for real software development. He chose a design that built readability directly into the language specification itself, such as enforcing block structure through indentation.

## Features

- Syntax that prioritizes readability above all, using indentation to represent structure
- A clear, consistent coding culture known as being "Pythonic"
- An ecosystem built on a standard library and a vast collection of third-party packages (pip)
- Dynamically typed, while also supporting static checking through type hints
- A de facto standard set of libraries for machine learning and data science (NumPy, PyTorch, etc.)

## Current Status

Its design philosophy of prioritizing readability has paid off, and Python remains one of the most widely used, actively developed languages across education, web development, scientific computing, machine learning, and more. Its presence in the AI and data science fields in particular is overwhelming, and it is expected to keep its central position going forward.
