# QBasic

- Year: 1991
- Designer(s): Microsoft
- Paradigm(s): procedural
- Family: origin

## Problem It Aimed to Solve

Microsoft needed to replace GW-BASIC, which had been bundled standard with MS-DOS, but could not simply distribute the commercial QuickBASIC for free. So it stripped the compiler and linker functionality out of QuickBASIC 4.5, developing QBasic as a lightweight implementation limited to interpreter functionality, and bundled it free of charge as a standard part of MS-DOS 5.0 and later, providing an environment where anyone could immediately start learning to program.

## Features

- Supports structured programming through SUB/FUNCTION, inherited from QuickBASIC
- An interpreter-only implementation with no compiler or linker, giving it a small file size and lightweight operation
- Served as an entry-level environment for many beginners, functioning as the editor and runtime environment bundled standard with MS-DOS
- Shipped with sample programs such as "GORILLA.BAS" and "NIBBLES.BAS," designed to let people learn while having fun

## Current Status

It is now positioned as a legacy language (status: legacy) with essentially no practical use, but it is still remembered fondly by the generation who learned programming on MS-DOS PCs in the 1990s as the first programming language they ever touched.
