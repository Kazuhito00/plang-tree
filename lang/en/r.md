# R

- Year: 1993
- Designer(s): Ross Ihaka, Robert Gentleman
- Paradigm(s): functional, array
- Family: numeric-scientific

## Problem It Aimed to Solve

In the 1990s, the commercial language S from Bell Labs was the de facto standard in the field of statistical analysis, but its high licensing costs were a barrier for students and researchers. Ross Ihaka and Robert Gentleman of the University of Auckland in New Zealand wanted to create an open-source statistical analysis environment that anyone could use for free while following S's syntax and functionality. Building on a lightweight implementation inspired by the design of Scheme interpreters, they developed a language specialized for statistical analysis and graphics. The name "R" both reflects the initials of the two designers' first names and pays homage to S.

## Features

- A rich set of built-in functions specialized for statistical analysis and data visualization
- A massive package ecosystem called CRAN (Comprehensive R Archive Network)
- Data structures centered on handling vectors and matrices at the core of the language
- Functional characteristics inherited from Scheme, such as lazy evaluation and first-class functions
- Completely free and open source, widely adopted in academic research

## Current Status

R remains an actively used language today (status: active), firmly established as an open-source language widely used by researchers and data scientists in statistical analysis and data visualization. It enjoys particularly strong support in fields such as reproducible analysis for academic papers and bioinformatics.
