# Rockstar

- Year: 2018
- Designer(s): Dylan Beattie
- Paradigm(s): procedural
- Family: esoteric

## Problem It Aimed to Solve

Rockstar was created to poke fun at the "Rockstar Developer" job-listing buzzword used in the tech industry. Developer Dylan Beattie set out to realize a joke: if he designed a Turing-complete language whose grammar read like the lyrics of 1980s hard rock or power ballads, then simply learning that grammar would let someone literally claim to "write Rockstar code." It drew its inspiration from languages with verbose, English-like syntax such as COBOL and Visual Basic.

## Features

- Variable declaration and assignment are written as poetic natural-language sentences such as "My heart is a stone"
- Has its own parser that interprets variable names and values from case-insensitive, natural-language-like token sequences
- Expresses loops and conditionals with English words such as "Until," "While," and "If," so that an entire program reads like a stanza of poetry
- Includes a mechanism called "literate numerals," which implicitly derives numeric values from the letter count of words
- Multiple implementations exist, running on platforms such as Node.js, and it has actually been confirmed to be Turing complete
- Though it began as a joke, it retains a dedicated community of enthusiasts who use it for code golf and parody purposes

## Current Status

Rockstar is positioned as a niche esoteric language and is not intended for practical use. Despite its joke origins, it has been implemented as a genuinely Turing-complete processing system, and it continues to be used in entertainment-oriented contexts such as code golf and conference demos.
