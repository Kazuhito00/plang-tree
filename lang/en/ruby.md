# Ruby

- Year: 1995
- Designer(s): Yukihiro Matsumoto
- Paradigm(s): object-oriented, functional
- Family: smalltalk-oop

## Problem It Aimed to Solve

In the early 1990s, Perl was widely used for text processing and system administration, but its grammar prioritized practicality at the expense of consistency. Smalltalk, meanwhile, achieved pure object orientation, but had drawbacks in practical usability. Yukihiro Matsumoto wanted to create a language that had Perl-like practical expressive power and Lisp's flexibility, while being built on the thoroughgoing object orientation inherited from Smalltalk, and above all that felt "fun for the programmer to write." The design philosophy underlying it prioritizes human productivity and satisfaction over efficiency and performance.

## Features

- Thoroughgoing object orientation inherited from Smalltalk, in which every value, including numbers and strings, is an object
- Naturally integrates functional elements such as blocks (closures) and iterators into the language
- Champions the "principle of least astonishment," emphasizing consistent syntax that follows the writer's intuition
- Mechanisms such as open classes and mix-ins that allow existing classes to be flexibly extended at runtime
- Became globally popular as a language for web application development following the advent of Ruby on Rails

## Current Status

Through Ruby on Rails, Ruby established itself as one of the leading languages for web development, and it remains an actively developed language today. Its design philosophy of "programmer happiness" is highly regarded worldwide as a language originating from Japan.
