# Shakti

- Year: 2018
- Designer(s): Arthur Whitney
- Paradigm(s): array, functional
- Family: numeric-scientific

## Problem It Aimed to Solve

More than a decade after developing kdb+/Q, Arthur Whitney needed a next-generation array language that would push performance and memory efficiency further on multi-core, large-scale parallel environments. It was developed to carry forward the design philosophy of the K language while achieving high parallelism and low memory usage on large datasets. It is intended for use in fields requiring heavy data processing, such as financial analysis.

## Features

- Retains the extremely concise array-oriented syntax inherited from K while overhauling the internal implementation
- Designed with an emphasis on execution performance in multi-core, large-scale parallel environments
- Optimized to minimize memory usage, making it suitable for processing large datasets
- Its array-oriented, functional programming style allows complex data transformations to be expressed with very little code
- Designed with practical use in mind for financial analysis and other domains requiring large-scale data processing

## Current Status

Shakti is positioned as a niche language, used in a limited set of specialized fields such as large-scale data processing and financial analysis, as a successor within the K-family lineage. It has not achieved widespread general-purpose adoption, but continues to draw attention as an implementation carrying forward Arthur Whitney's design philosophy.
