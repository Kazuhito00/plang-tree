# Small Basic

- Year: 2008
- Designer(s): Vijaye Raji, Microsoft
- Paradigm(s): procedural, event-driven
- Family: educational-visual

## Problem It Aimed to Solve

There was a need to provide children and beginners moving up from visual programming environments like Scratch to text-based programming with an entry point they could learn without strain. Small Basic was designed to pare its set of keywords down to an absolute minimum (about 14 by default) and, combined with a simple IDE, let beginners learn the fundamental concepts of programming without being defeated by syntactic complexity. It was developed by Microsoft as an educational project.

## Features

- Has an extremely simple grammar, narrowed down to around 14 keywords in use
- Provides, as standard, objects such as turtle graphics and a GraphicsWindow that give easy visual feedback
- Comes with a dedicated lightweight IDE equipped with IntelliSense (autocompletion), so beginners can write code without getting lost
- Its event-driven programming model makes it easy to write handlers for mouse and keyboard input
- Designed so that, once mastered, learners can move smoothly on to more full-featured languages such as Visual Basic

## Current Status

Small Basic is positioned as an educational-purpose language, used as introductory teaching material for programming beginners, especially children. It plays the role of a bridge from visual languages to full-fledged text-based languages.
