# Smalltalk

- Year: 1972
- Designer(s): Alan Kay and others (Xerox PARC)
- Paradigm(s): object-oriented
- Family: smalltalk-oop

## Problem It Aimed to Solve

In the early 1970s, Alan Kay and others at Xerox PARC held a vision called "Dynabook," a personal computer that even a child could use. Rather than the existing batch-processing view of computation, they wanted to build a flexible system, like a collection of biological cells, in which everything is an "object" and objects operate by sending messages to one another. Taking hints from Simula's class concept and from Lisp's symbolic processing and interactive environment, their goal was to implement this vision uncompromisingly in its pure form, realizing it as a personal computing environment complete with a GUI.

## Features

- A thoroughly pure object-oriented model in which "everything is an object, and every operation is a message send"
- One of the earliest languages to establish the basic vocabulary of modern OOP: classes, instances, and inheritance
- A live-coding environment (an integrated image, browser, and debugger IDE) that lets the running system itself be edited while it executes
- One of the earliest practical implementations of GUI elements now in wide use, such as overlapping windows, menus, and mouse operation
- Dynamic typing and a lightweight syntax that enabled programming through interactive trial and error

## Current Status

Its adoption as a mainstream commercial language has been limited (niche), but its position in the history of computer science is unshakeable as the wellspring of two enormous currents: object-oriented programming and the GUI. Descendant implementations such as Pharo continue to be used today for research and educational purposes.
