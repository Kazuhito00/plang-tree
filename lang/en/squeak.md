# Squeak

- Year: 1996
- Designer(s): Alan Kay, Dan Ingalls, Ted Kaehler, John Maloney, Scott Wallace
- Paradigm(s): object-oriented
- Family: smalltalk-oop

## Problem It Aimed to Solve

Smalltalk-80 was locked into commercial vendors' implementations, and no open implementation existed that anyone could freely modify or port. The researchers at Apple who had once created Smalltalk wanted to provide, free of charge for education and research, a fully self-describing system that could be ported to any platform and whose own implementation could be rewritten in Smalltalk code itself. Underlying this was also Alan Kay's consistent educational vision of creating a learning environment in which children could freely express their own ideas on a computer.

## Features

- Faithful to the Smalltalk-80 specification, while being a self-describing system whose implementation is itself written in Smalltalk
- Designed to be portable to any platform, with the virtual machine itself written in Smalltalk
- Has a live graphical object framework called Morphic, allowing every element on screen to be manipulated directly
- Includes Etoys, a visual programming environment, and has also developed as an educational tool for children
- Released as open source, allowing anyone to freely modify and redistribute it

## Current Status

Squeak is positioned as a niche language used in specific fields, and it continues to be used today in education and in research on self-describing systems. While many users have migrated to its successor Pharo, Squeak itself also maintains its own community.
