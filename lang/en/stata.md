# Stata

- Year: 1985
- Designer(s): William Gould, Sean Becketti
- Paradigm(s): procedural, scripting
- Family: domain-specific

## Problem It Aimed to Solve

In the mid-1980s, personal computer performance was improving, but statistical analysis software that could be used affordably on such machines was still limited. Stata was developed with the aim of allowing researchers to carry out data management, statistical analysis, and visualization consistently within a single environment. It also aimed to provide a flexible system capable of keeping up with ever-evolving research needs by letting users themselves extend commands and incorporate their own statistical methods and analytical procedures.

## Features

- Supports both interactive operation via the command line and batch processing via scripts called do-files
- Users can define and distribute their own commands (ado files), and a community-driven ecosystem of extension packages has developed
- Comes standard with a rich set of statistical methods needed in fields such as economics and epidemiology, including regression analysis, panel data analysis, and survival analysis
- Follows a style of loading a dataset into memory and processing it in bulk, with an intuitive set of data-manipulation commands
- Graph-generation commands are integrated, allowing analysis results to be output directly as figures suitable for papers

## Current Status

It is actively and widely used today. It continues to be widely used by researchers and analysts in economics, epidemiology, and the social sciences, and it retains its standing as a tool that supports the reproducibility of academic research.

## Hello World

Stata's `display` command is the basic means of displaying an expression or string directly to the console.

```stata
display "Hello, World!"
```
