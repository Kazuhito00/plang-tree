# True BASIC

- Year: 1985
- Designer(s): John G. Kemeny, Thomas E. Kurtz
- Paradigm(s): procedural, array
- Family: origin

## Problem It Aimed to Solve

True BASIC is a language developed by John Kemeny and Thomas Kurtz, the original creators of BASIC, to push back against the proliferation of Microsoft BASIC-family dialects and to promote the concept of structured programming together with an ANSI-standard BASIC. It enabled structured code that did not depend on line numbers or GOTO statements, while still retaining compatibility with existing BASIC. It included features aimed at education and scientific computing, such as native support for matrix operations and local variables that enabled recursion. Its hardware-independent design also aimed to ensure code portability across different machines.

## Features

- Eliminates dependence on GOTO statements and line numbers, introducing structured control constructs such as DO/LOOP and SELECT CASE
- Natively supports matrix (array) operations, letting matrix addition, subtraction, and multiplication be written directly with the MAT statement
- Allows functions and subroutines to have local variables and supports recursive calls
- Conforms to ANSI standard BASIC (ANSI X3.113), designed to produce highly portable code that does not depend on the machine
- Provides a rich set of graphics instructions and mathematical functions aimed at scientific and technical computing
- Provides an interactive development environment, intended for use in educational institutions and scientific computing settings

## Current Status

True BASIC is scarcely used today as a practical programming language and is positioned as a language whose historical role is over. Its design philosophy of pursuing standardized, structured BASIC influenced later BASIC implementations, but the language itself saw its commercial deployment shrink, and it remains in use mainly among educators and hobbyists.
