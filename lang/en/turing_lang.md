# Turing

- Year: 1982
- Designer(s): Ric Holt, James Cordy
- Paradigm(s): procedural, object-oriented
- Family: algol-pascal

## Problem It Aimed to Solve

In the early 1980s, introductory university programming education was hampered by the complex syntax rules of existing languages such as Pascal. Ric Holt and James Cordy of the University of Toronto drew on their experience with Pascal, Euclid, and SP/k to design Turing, an educational language with syntax intended to be easy to read and easy to learn. By eliminating the need for semicolons and using explicit terminating keywords (such as `end if`), they made it possible for beginners to write code whose structure was easy to understand. Turing was adopted widely in high schools in Ontario and played a major role as an educational language.

## Features

- Retains Pascal's block structure while adopting a more concise syntax that allows semicolons to be omitted
- Uses explicit terminating keywords such as `end if` and `end for`, making the correspondence between blocks visually clear
- Supports modules and an object-oriented extension (Object-Oriented Turing), covering everything from educational use to practical development
- Emphasizes type safety in its design, making it easier to catch beginners' common mistakes at compile time
- Provides an interactive execution environment, letting learners check results immediately while they learn to program

## Current Status

Turing has long been used mainly as an educational language in Canadian schools, particularly in Ontario, and its use today remains centered on education. It never saw wide adoption in commercial or industrial settings, and is positioned as a language specialized for educational purposes.

## Hello World

In Turing, the `put` statement is used to print a string.

```turing
put "Hello, world!"
```
