# X10

- Year: 2004
- Designer(s): Kemal Ebcioğlu, Vijay Saraswat, Vivek Sarkar
- Paradigm(s): object-oriented, concurrent, procedural
- Family: numeric-scientific

## Problem It Aimed to Solve

X10 was developed by IBM under DARPA's High Productivity Computing Systems (HPCS) initiative to realize a programming model that could handle petascale massively parallel computers with high productivity. Traditional parallel programming required dealing with low-level details in order to extract performance, which was a major barrier to productivity. X10 therefore adopted the PGAS (Partitioned Global Address Space) model and combined it with a Java-like object-oriented syntax, aiming to be a language that could naturally express asynchronous tasks and distributed data. Its goal was to make programming on large-scale parallel computers feel close to programming in an ordinary object-oriented language.

## Features

- Adopts the PGAS model, allowing data and tasks distributed across multiple "places" to be handled uniformly within a single program
- The `async`/`finish` syntax allows the creation of asynchronous tasks and waiting for their completion to be expressed concisely
- Adopts a Java-like object-oriented syntax, with type safety and generics
- Has distributed arrays and iteration spaces (regions) as language features, allowing data-parallel processing to be expressed declaratively
- Implementations were provided targeting IBM mainframe and supercomputer environments

## Current Status

X10 is positioned as a legacy language, maintained conservatively. Active development by IBM has already ended, and it is currently used only for limited research and maintenance purposes.

## Hello World

X10 outputs text using `Console.OUT.println`, in a syntax resembling Java.

```x10
class HelloWorld {
    public static def main(args: Rail[String]) {
        Console.OUT.println("Hello, World!");
    }
}
```
