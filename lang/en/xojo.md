# Xojo

- Year: 1998
- Designer(s): Andrew Barry, Geoff Perlman
- Paradigm(s): object-oriented, event-driven, visual
- Family: origin

## Problem It Aimed to Solve

At the time, the Macintosh had no easy RAD (rapid application development) environment comparable to Visual Basic on Windows. Xojo (originally named REALbasic) was born out of the motivation to achieve the same kind of productivity as Visual Basic on the Mac, through an object-oriented BASIC-family language. It later developed into an environment for building applications for multiple platforms — desktop, mobile, and web — from a single language and codebase.

## Features

- Has a visual GUI builder with drag-and-drop functionality, allowing forms and controls to be placed visually
- Integrates object-oriented concepts (classes, inheritance, interfaces) into plain BASIC-family syntax
- Can build for multiple platforms — Windows, macOS, Linux, Web, iOS, and Android — from a single codebase
- Adopts an event-driven programming model, making it easy to write processing in response to GUI operations
- Provided as a commercial integrated development environment, sold as a RAD tool for businesses and individual developers

## Languages It Influenced

Its direct influence on later languages appears to be limited.


## Current Status

Xojo is positioned as a niche language used in a specific field. It continues to be offered and maintained today as a commercial product for individual developers and small to medium-sized businesses working on cross-platform business application development.
