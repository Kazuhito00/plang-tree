# 易语言 (E Language)

- Year: 2000
- Designer(s): 吴涛 (Wu Tao)
- Paradigm(s): procedural, object-oriented, scripting
- Family: scripting

## Problem It Aimed to Solve

For Chinese speakers, English-based keywords and programming terminology were a barrier to learning. Designer Wu Tao aimed to build a development environment in which every construct, function, and keyword could be written in Chinese, in order to put into practice the idea of "writing programs in Chinese." It adopted a Visual Basic-like visual development environment and library mechanism, aiming to let even beginners build Windows applications in a short time. It became popular within China for education and for building simple business applications, but it is little known abroad, and its reputation is mixed given reports that it has also been abused to create malware.

## Features

- Every keyword, statement, and function name can be written in Chinese, allowing programs to be written without any knowledge of English
- Includes a Visual Basic-like visual form designer that lets GUI components be placed via drag and drop
- A module mechanism called "支持库 (support libraries)" allows APIs and functionality to be added and extended later
- A procedural language that can call the Windows API directly, and compiles to native executable files
- Also supports object-oriented class definitions, suited to building simple business applications
- Its low learning cost has made it popular for beginner education and simple business systems within China, though it is also known to have been abused to create malware
