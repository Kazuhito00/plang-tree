# Zsh

- Year: 1990
- Designer(s): Paul Falstad
- Paradigm(s): scripting, procedural
- Family: shell

## Problem It Aimed to Solve

By 1990, the Bourne Shell (sh) and Bash were already widely used, but there remained room for improvement in areas such as completion features, spelling-mistake correction, and interactive customizability.

Paul Falstad, then a student at Princeton University, developed Zsh to create an interactive shell that incorporated the good parts of existing shells such as sh, Bash, and the C shell, while being more capable and flexibly customizable. It began as a personal project, but features were gradually added and it developed into an independent shell.

## Features

- Built on sh/Bash-compatible syntax while adding numerous original extended syntax constructs
- Has an extremely powerful and highly extensible tab-completion system
- Allows advanced customization through plugins and themes
- Rich in features that emphasize interactive operation, such as spelling-mistake correction and advanced shared history
- Extensive extensions to glob (wildcard) patterns, allowing flexible file operations
- Adopted as the default shell on macOS in 2019, which greatly increased its user base

## Current Status

Zsh retains a devoted following thanks to its advanced completion features and customizability, and its adoption as the default shell on macOS further widened its user base.

Community configuration frameworks such as Oh My Zsh have also become popular, and it remains in active use today as an interactive shell for developers.
