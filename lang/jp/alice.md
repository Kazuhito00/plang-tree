# Alice

- 登場年: 1999年
- 設計者: Randy Pauschほか(CMU)
- パラダイム: educational, visual, object-oriented
- 系統: educational-visual

## 解決したかった課題

オブジェクト指向プログラミングはクラスやメソッド、インスタンスといった抽象的な概念を扱うため、特にプログラミング初学者や女性など従来のCS教育に馴染みの薄い層にとって取っつきにくいという課題があった。

カーネギーメロン大学のRandy Pauschらは、Logoのようにキャラクターを動かして学ぶ発想を発展させ、3Dアニメーションのキャラクターをドラッグ&ドロップの命令で動かす体験を通じて、遊びながら自然にオブジェクトとメソッド呼び出しの概念を学べる環境としてAliceを開発した。

## 特徴

- 3Dキャラクターやオブジェクトをドラッグ&ドロップのブロックで操作してアニメーションを作る
- 内部的にはオブジェクト指向のクラス・メソッド・インスタンスの概念に対応した操作になっている
- 構文エラーが起きない視覚的なプログラム構築方式を採用
- アニメーションやストーリー制作を通じて、楽しみながらプログラミングの初歩を学べる
- ドラッグ&ドロップの操作がそのまま裏側でJavaライクなコードに対応しており、後の言語学習への橋渡しとなる
- 主に大学・高校のCS入門教育で導入され、初学者の離脱率低減に効果があったと報告されている

## 現在の位置づけ

Aliceは3Dアニメーション制作を通じてオブジェクト指向の概念を学ぶ教育用環境として、大学の入門講義などで現在も利用されている。

テキストベース言語への移行前段階の教材として、プログラミング教育における独自の位置づけを保っている。

## Hello World

Aliceはドラッグ&ドロップでオブジェクトにメソッドを組み立てるビジュアル言語のため、テキストコードの代わりに操作手順を擬似コードとして示す。

```
[ワールドに3Dキャラクター(オブジェクト)を1体配置する]
[そのオブジェクトが持つ「say」メソッドをエディタ上のイベント欄にドラッグ&ドロップする]
[メソッドの引数に "Hello, World!" と入力する]
[実行(Run)ボタンを押すと、キャラクターが吹き出しで "Hello, World!" と発言する]
```
