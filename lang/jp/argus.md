# Argus

- 登場年: 1983年
- 設計者: Barbara Liskov, Maurice Herlihy, Paul Johnson, Robert Scheifler, William Weihl
- パラダイム: object-oriented, concurrent
- 系統: concurrent-actor

## 解決したかった課題

1980年代、分散システムでは複数のマシン上で動くプログラムの障害耐性や一貫性の保証が大きな課題であった。MITのBarbara Liskovらは、自身が設計したCLU言語を拡張し、分散プログラムを堅牢に構築するための言語Argusを開発した。関連する手続きをカプセル化する「ガーディアン」と呼ばれるオブジェクトと、原子性を保証する「アクション」という概念を導入し、部分的な障害が発生してもデータの一貫性を保てる仕組みを提供した。この研究は後の分散システムやトランザクション処理の言語設計に影響を与えた。

## 特徴

- CLUのクラスタ(抽象データ型)機構を継承しつつ、分散環境向けに拡張されている
- 関連する手続きとデータをカプセル化する「ガーディアン(guardian)」という単位でプログラムを構成する
- トランザクションの概念に相当する「アクション(action)」を導入し、複数マシンにまたがる操作の原子性・一貫性を保証する
- 部分的な障害(クラッシュやネットワーク分断)が発生してもデータが不整合な状態に陥らない仕組みを提供する
- ネストされたアクションにより、複雑な分散処理を段階的に構成できる

## 現在の位置づけ

Argusは実用的なプログラミング言語として広く使われることはなく、研究上の役割を終えた歴史的な言語として位置づけられている。ガーディアンやアトミックアクションといった概念は、その後の分散トランザクション処理システムやRPC設計の研究に影響を与え、分散システム研究史における重要な事例として参照され続けている。

## Hello World

Argusは分散オブジェクトである「ガーディアン」を単位とし、CLU由来のストリーム出力プリミティブを用いる。

```
hello = guardian is start
    start = proc ()
        po: stream := stream$primary_output()
        stream$putl(po, "Hello, world!")
    end start
end hello
```
