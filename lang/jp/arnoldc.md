# ArnoldC

- 登場年: 2012年
- 設計者: Lauri Hartikka
- パラダイム: esoteric, procedural
- 系統: esoteric

## 解決したかった課題

ArnoldCは、映画俳優アーノルド・シュワルツェネッガーの数々の名台詞だけでプログラムの制御構造(if文やループ、関数定義)を表現するという、ファン心理とプログラミングを掛け合わせたジョークとして作られた。「I'll be back」がループの終了を表し、「GET TO THE CHOPPER」が関数の開始を表すなど、映画の名台詞を律儀に構文要素へマッピングすること自体が目的であり、実用的なプログラミング上の課題を解決する意図は最初からない。

## 特徴

- 変数宣言・条件分岐・ループ・関数定義など、通常のプログラミング構文の要素すべてが映画の名台詞に対応づけられている
- プログラムの開始・終了にも「IT'S SHOWTIME」「YOU HAVE BEEN TERMINATED」のような台詞が使われる
- 大文字だけで台詞をそのまま書くスタイルのため、見た目は映画の名場面集のようになる
- 変数への加算・減算にも「GET UP」「GET DOWN」のような比喩的な命令名が使われる
- 見た目のインパクトの強さに反し、実際には手続き型言語として一通りの制御構造を備えている

## 現在の位置づけ

## Hello World

「IT'S SHOWTIME」でプログラムを開始し、「TALK TO THE HAND」で文字列を出力し、「YOU HAVE BEEN TERMINATED」で終了する、ArnoldCの定番Hello Worldプログラムである。

```
IT'S SHOWTIME
TALK TO THE HAND "Hello, world!"
YOU HAVE BEEN TERMINATED
```
