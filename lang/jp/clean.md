# Clean

- 登場年: 1987年
- 設計者: Rinus Plasmeijer, Marko van Eekelen
- パラダイム: functional
- 系統: ml-functional

## 解決したかった課題

Cleanは、純粋関数型プログラミングの数学的な美しさを保ちながら、効率的なコード生成と入出力・状態の扱いという実践上の課題を両立させることを目指して開発された。純粋関数型言語では副作用の扱いが難題となるが、Haskellが採用したモナドとは異なるアプローチとして、一意型システム(uniqueness typing)を導入した。この仕組みによって、値が一度しか参照されないことを型レベルで保証し、破壊的な更新を安全に行いながら実行効率を高めることを狙った。オランダのネイメーヘン大学で研究言語として開発が始まった経緯を持つ。

## 特徴

- 一意型システムにより、値の所有権が一つに限られることを型で保証し、安全な破壊的更新を可能にしている
- 純粋関数型言語でありながら、モナドを使わずに入出力や可変状態を扱える独自のアプローチを採用している
- 遅延評価をデフォルトとし、必要な計算だけを行うことで効率性を高めている
- グラフ書き換え系をベースにした処理系を持ち、関数型言語の理論的な基盤を実装レベルで体現している
- GUIツールキット(Object I/O)を標準で提供し、対話的アプリケーションの開発にも対応する

## Hello World

CleanのプログラムはStart関数がエントリポイントとなり、その値が結果として出力される。

```
module hello

Start :: String
Start = "Hello, World!"
```
