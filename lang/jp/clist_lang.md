# CLIST

- 登場年: 1973年
- 設計者: IBM
- パラダイム: procedural, scripting
- 系統: shell

## 解決したかった課題

IBMメインフレームのTSO(Time Sharing Option)環境では、利用者が繰り返し行うコマンド操作を自動化する手段が求められていた。CLIST(Command List、「シーリスト」と発音される)は、OS/360 Release 20の頃に登場し、当初は単に「順番に実行するコマンドの列」という単純な仕組みにすぎなかった。

その後のバージョンでは、IF/THEN/ELSEなどの条件分岐やループ、パラメータ渡し、グローバル変数といった機能が追加され、MVSファイルの読み書きやTSO端末との対話、バックグラウンド実行、ISPFダイアログサービスの呼び出しにも対応する、本格的な手続き型スクリプト言語へと発展した。

## 特徴

- 実行時にインタプリタが逐次変換して実行する、コンパイル不要のインタプリタ型言語
- 基本形は「順番に実行するコマンドのリスト」だが、条件分岐・ループなどの制御構造を後から獲得した
- MVS上のファイルやTSO端末への入出力を扱える
- パラメータ渡しとグローバル変数をサポートし、外部のMVSアプリケーションを呼び出せる
- バックグラウンド実行やISPFダイアログサービスとの連携が可能

## 現在の位置づけ

TSO/E Version 2でREXXが利用可能になって以降、CLISTは補完的な位置づけとなり、新規開発ではほとんど使われなくなった。今日では、過去に書かれたCLISTスクリプトを保守する目的で稼働システムに残存している歴史的言語である。
