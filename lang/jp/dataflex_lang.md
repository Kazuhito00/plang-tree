# DataFlex

- 登場年: 1982年
- 設計者: Data Access Corporation
- パラダイム: procedural, object-oriented
- 系統: domain-specific

## 解決したかった課題

1980年代初頭、コンピュータ業界では多様なハードウェアやOSが並存しており、あるシステム向けに書いたアプリケーションコードを別の環境でそのまま動かすことは難しかった。Data Access Corporation(現Data Access Worldwide)は、この移植性の問題を解決するため、1982年にDataFlexを開発した。

独自の中間バイトコードへコンパイルする方式を採用することで、ハードウェアアーキテクチャに依存せずアプリケーションコードを実行できるようにした点が最大の特徴である。データベース処理を中心とした第4世代言語(4GL)として設計され、後年にはOracle、SQL Server、MySQL、PostgreSQLなど複数のデータベースバックエンドに対応するようになった。

## 特徴

- 独自の中間バイトコードへのコンパイルによる高い移植性
- 複数のデータベースバックエンド(Oracle、SQL Server、MySQL、PostgreSQLなど)に対応
- ルースな型付けと自動的な型変換
- 継承やサブクラス化をサポートするオブジェクト指向機能
- Windows、Web、モバイルの各プラットフォームに対応する開発環境(IDE)を提供
