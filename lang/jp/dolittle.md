# ドリトル

- 登場年: 2000年
- 設計者: 兼宗進、久野靖
- パラダイム: object-oriented, educational, visual
- 系統: educational-visual

## 解決したかった課題

2000年前後、日本の小中学校における情報教育では、英語ベースの構文につまずくことなくプログラミングの基本概念を学べる教材が求められていた。兼宗進(現・大阪電気通信大学教授)と久野靖は、日本語の語順(主語・目的語・述語)でオブジェクトを操作できる言語であれば、児童・生徒がオブジェクト指向やタートルグラフィックスの考え方に自然に触れられると考え、ドリトルを設計した。名称は「ちょっとしたプログラミング(do little)」と、ヒュー・ロフティングの小説『ドリトル先生』の両方に由来する。

## 特徴

- 命令を日本語の主語・目的語・述語の語順で記述できる
- 「タートル」と呼ばれるカーソルを操作して図形を描くタートルグラフィックス機能を持つ
- オブジェクトはプロトタイプベースで扱われ、あらかじめ用意された部品を組み合わせて動かしながらオブジェクト指向の考え方を学べる
- 図形の移動時に自動で衝突判定を行う機能を持つ
- ドレミの階名で作曲できる「ストトン記法」による音楽機能も備える
- フリーウェアとして公開され、小中学校の情報教育やプログラミングスクールの教材として広く使われている

## 現在の位置づけ

日本語による教育用オブジェクト指向言語として、現在も初等・中等教育のプログラミング教材として利用されている。

## Hello World

ドリトルには専用のコンソール出力命令はなく、「ラベル」というGUI部品を作ることで文字列を画面に表示する。

```
ラベル1＝ラベル！"Hello, World!"　作る。
```
