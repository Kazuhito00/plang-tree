# FALSE

- 登場年: 1993年
- 設計者: Wouter van Oortmerssen
- パラダイム: esoteric, stack-based
- 系統: esoteric

## 解決したかった課題

FALSEは、たった1024バイトという極小のコンパイラで、Forth的なスタックベース言語をどこまで機能的に実装できるかを試す挑戦として作られた。実用性そのものよりも、コンパイラの実装サイズを極限まで切り詰めるという制約下で言語機能をどこまで残せるかというミニマリズムの実験であり、その結果生まれた記号だらけの簡潔な構文は、後に難解言語というジャンルの起点の一つになった。名前の「FALSE」自体、実用性の否定を暗示するような、ひねりの効いたジョーク名でもある。

## 特徴

- Forthに似たスタックベースの演算モデルを持ちながら、命令の多くが1〜2文字の記号に切り詰められている
- 変数名は原則としてa〜zの1文字のみに制限され、名前空間の概念が最小限に削られている
- コンパイラの実装がわずか1024バイトに収まるよう、言語仕様自体が極端に単純化されている
- 制御構造(条件分岐・ループ)もブロック(`[...]`)と記号命令の組み合わせだけで表現する
- ソースコードは極めて短く書けるが、可読性は大きく犠牲になっている

## 現在の位置づけ

esoteric(難解言語)として位置づけられ、実用目的では使われない。極小コンパイラの実験という側面から、難解言語黎明期を代表する作品の一つとして、後続の難解言語設計者たちに参照され続けている。

## Hello World

FALSEでは文字列リテラルをソースコード上にそのまま書くだけで、その場で標準出力へ書き出される。そのため「Hello, World!」の出力は次の1行だけで完結する。

```
"Hello, World!"
```
