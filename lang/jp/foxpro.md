# FoxPro

- 登場年: 1984年
- 設計者: Fox Software
- パラダイム: procedural, object-oriented, query
- 系統: domain-specific

## 解決したかった課題

dBaseはパソコン向けデータベース管理ソフトの草分けとして広く普及したが、インタプリタ方式による実行速度の遅さや、大規模な業務アプリケーションを構築する上での機能不足が指摘されていた。

Fox Softwareは、dBaseの.dbf形式やコマンド体系との互換性を保ちながら、コンパイル方式による高速化と、より高度な開発環境(画面デザイナやレポート作成機能など)を提供する製品としてFoxProを開発した。互換性を維持することで既存のdBaseユーザーが移行しやすい点も、市場開拓上の重要な狙いだった。

## 特徴

- dBaseのコマンドとデータ形式(.dbf)に高い互換性を持つ
- コンパイル実行により、インタプリタ型のdBaseより大幅に高速に動作する
- 後のバージョンではオブジェクト指向のクラス機構を取り入れ、フォームやコントロールを部品として再利用できる
- 画面デザイナやレポートビルダーなど、業務アプリケーションを視覚的に組み立てるRAD環境を備える
- Microsoftに買収された後もVisual FoxProとして長く保守され、業務システム開発で使われ続けた
- テーブル操作の構文がプログラム言語に直接組み込まれており、SQL的な問い合わせも記述できる

## 現在の位置づけ

FoxProは現在ではレガシーな言語であり、Microsoftによるサポート終了後は新規開発での採用はほぼ見られないが、1990年代から2000年代にかけて多くの中小企業向け業務システムを支えた実績を持つ。今なお稼働中の古いVisual FoxProアプリケーションの保守需要は一部で残っている。
