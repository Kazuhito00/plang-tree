# GLSL

- 登場年: 2002年
- 設計者: John Kessenich, Dave Baldwin, Randi Rost
- パラダイム: procedural, concurrent
- 系統: hardware-description

## 解決したかった課題

2000年代初頭のOpenGLでは、シェーダ(頂点・ピクセルごとの描画処理をプログラムで記述する仕組み)を扱う際、低レベルなアセンブリ形式の命令列を直接書く必要があり、複雑な視覚効果を実現しようとすると非常に煩雑で保守しづらいコードになっていた。KessenichらはOpenGL ARB(標準化団体)のもとで、C言語に似た読みやすい高水準の構文でシェーダを記述できる言語を作りたいと考えた。オープン標準であるOpenGLの利点を保ちながら、頂点処理やピクセル(フラグメント)処理を直感的にプログラマブルに記述できる仕組みを提供することで、シェーダプログラミングをより多くの開発者に開放しようとした。

## 特徴

- C言語に似た構文を持ち、頂点シェーダ・フラグメントシェーダなどGPU上で並列実行される処理を記述できる
- ベクトル型・行列型が組み込みで用意され、3Dグラフィックスに必要な演算を簡潔に表現できる
- 各シェーダ呼び出しが独立して大量に並列実行されることを前提とした設計になっている
- OpenGL(および後継のOpenGL ES、WebGL)というオープン標準規格に組み込まれ、幅広いプラットフォームで利用されている
- HLSL(DirectX向け)と並び、リアルタイムグラフィックス分野で広く使われる代表的なシェーディング言語である

## 現在の位置づけ

active(現役で広く使われている言語)であり、OpenGL・OpenGL ES・WebGLを用いたリアルタイム3Dグラフィックス開発において、現在も標準的なシェーディング言語として広く使われ続けている。

## Hello World

GLSLはグラフィックス処理向けの言語であるため文字列出力の概念はないが、フラグメントシェーダで単色を出力する最小限の例は次のようになる。

```glsl
void main() {
    gl_FragColor = vec4(1.0, 1.0, 1.0, 1.0); // "Hello, World!" の代わりに白色を出力
}
```
