# Gofer

- 登場年: 1991年
- 設計者: Mark P. Jones
- パラダイム: functional, declarative, pattern-matching
- 系統: ml-functional

## 解決したかった課題

Goferは、1990年代初頭のパーソナルコンピュータ上でも動作する軽量な処理系で、関数型プログラミングを教育・研究できるようにするために開発された。当時のフルスペックのHaskell処理系は、一般的なパソコンには重すぎて実用的ではなかった。そこでMark P. Jonesは、Haskell 1.2相当の言語仕様をベースにしたサブセットを設計し、これに型クラスなど独自の拡張を加えた小型のインタプリタとして実装した。限られた計算資源の中でも、型クラスという先進的な機能を試せる環境を提供することを狙った点が特徴である。

## 特徴

- Haskell 1.2をベースとした軽量なサブセットとして設計され、小規模なマシンでも動作するインタプリタとして実装された
- 型クラスの拡張(複数パラメータ型クラスなど)を独自に取り入れ、Haskellの標準化にも影響を与える先進的な機能を持っていた
- パターンマッチングと遅延評価を備え、Haskell系言語の基本的なプログラミングスタイルを踏襲している
- 対話的な実行環境を提供し、教育現場での関数型プログラミング学習に適した設計になっている
- 小型軽量であることを重視し、フル機能のコンパイラ実装ではなくインタプリタとして提供された

## 現在の位置づけ

historical(歴史的役割を終えた)言語として位置づけられる。後継処理系であるHugsに開発が引き継がれたことで、Gofer自体の開発と利用は終了している。

## Hello World

Goferではmain関数の評価結果が出力される、Haskell系言語に共通したスタイルを採用している。

```
main = putStr "Hello, World!\n"
```
