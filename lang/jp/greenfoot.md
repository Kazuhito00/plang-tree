# Greenfoot

- 登場年: 2006年
- 設計者: Michael Kölling, Poul Henriksen
- パラダイム: object-oriented, visual, event-driven
- 系統: educational-visual

## 解決したかった課題

オブジェクト指向プログラミングの中核概念であるクラス、オブジェクト、継承、ポリモーフィズムは、コードだけを眺めていても初学者には理解しづらい。Greenfootは、これらの概念をJavaという実用言語をベースにしながら、2Dのシミュレーションやゲームという目に見える形で体験させることでこの問題に取り組んだ。書いたコードがキャラクターの動きとして即座に画面上で確認できるため、クラス定義とオブジェクトの振る舞いの対応関係を直感的に学べる教育環境を目指した。

## 特徴

- Javaのソースコードをそのまま書きながら、クラスをアイコンとして視覚的に配置・継承関係を表示するハイブリッドな開発環境
- 「アクター」と呼ばれるオブジェクトを2Dワールド上に配置し、各アクターのメソッド呼び出しを対話的に実行して結果を即座に確認できる
- 通常のJavaコンパイラ・実行系をそのまま利用しており、言語仕様自体はJavaと完全に共通している
- ゲームやシミュレーションのフレームごとの更新処理(act メソッド)を通じてイベント駆動的なプログラム構造を学べる
- 継承関係のクラス図がエディタ上に常時表示され、オブジェクト指向設計の可視化を重視している

## 現在の位置づけ

教育用途で使われている。中等教育から大学教養課程までのJava入門コースで、オブジェクト指向を実践的に学ばせる教材として現在も採用され続けている。

## Hello World

アクタークラスの`act`メソッド内で、Greenfoot標準のメッセージ出力を使ってコンソールに文字列を表示する。

```java
public class MyActor extends Actor
{
    public void act()
    {
        System.out.println("Hello, World!");
    }
}
```
