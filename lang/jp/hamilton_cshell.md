# Hamilton C shell

- 登場年: 1988年
- 設計者: Nicole Hamilton
- パラダイム: scripting, procedural
- 系統: shell

## 解決したかった課題

Unix系のCシェル(csh)に慣れたユーザーが、MS-DOSやOS/2、後のWindows環境でも同様の対話型シェルとスクリプト機能を利用できるようにすることを目的として開発された。Nicole Hamiltonは既存のCシェルの実装コードを一切流用せず、完全に独自の実装として書き直し、その一方でWindows固有のドライブ文字やバックスラッシュによるパス区切り、エスケープ文字の扱いなど、Windowsの慣習にも合わせて設計した。

## 特徴

- トップダウン再帰下降パーサーを採用し、複雑な入れ子構造やパイプ処理を可能にしている
- Unixのforkの代わりにスレッドを用いてプロセス管理を実現している
- ドライブ文字やファイル名のスラッシュ、エスケープ文字などWindowsの慣習を直接サポート
- 組み込み関数・ユーザー定義プロシージャ、ローカル変数、浮動小数点演算など言語機能を拡張
- 複数階層のディレクトリにマッチする「...」というワイルドカード表記を持つ
- 商用プロプライエタリソフトウェアとして現在も販売・保守が継続している

## 現在の位置づけ

Hamilton C shellは、Windows上でUnix系シェルの操作感を再現する商用ソフトウェアとして開発から30年以上を経た現在も販売が続く、数少ない生きたcshクローンである。UTF-8対応やLinux版の計画など、限定的ながら開発は継続しているものの、主流のシェル環境ではなくニッチな位置づけにある。
