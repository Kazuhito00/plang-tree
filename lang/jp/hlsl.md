# HLSL

- 登場年: 2002年
- 設計者: Microsoft
- パラダイム: procedural, array
- 系統: hardware-description

## 解決したかった課題

DirectX初期の時代、頂点シェーダーやピクセルシェーダーはGPUのアセンブリ言語で直接記述する必要があり、開発効率が悪く保守も困難だった。MicrosoftはDirectX 9のリリースに合わせて、C言語に似た高水準の文法でGPUシェーダーを記述できるHLSLを開発した。同時期にNVIDIAが開発したCgと設計面で多くを共有しており、両者はほぼ同一の言語として登場した経緯がある。ハードウェアに依存しない高水準表現とコンパイラによる最適化を両立させ、シェーダー開発の生産性を大きく向上させた。

## 特徴

- C言語に似た構文を採用し、関数・構造体・制御構文などをそのまま利用できる
- 頂点シェーダー、ピクセルシェーダー、ジオメトリシェーダー、コンピュートシェーダーなど複数のシェーダーステージを単一の言語で記述できる
- `float4`や`float4x4`などベクトル・行列型が組み込みで用意され、グラフィックス計算を簡潔に表現できる
- セマンティクス(`: POSITION`や`: SV_Target`など)によって変数とGPUパイプラインの入出力を明示的に対応付ける
- DirectXのバージョンに応じたシェーダーモデルごとにコンパイルされ、ターゲットGPU世代に応じた最適化が行われる
- NVIDIAのCgと構文・設計思想を共有しており、初期には事実上の姉妹言語として扱われていた

## 現在の位置づけ

現役の言語であり、DirectXおよびWindowsグラフィックスエコシステムにおける標準シェーディング言語として広く使われ続けている。ゲーム開発をはじめとするリアルタイムグラフィックス分野で中心的な役割を担っている。

## Hello World

シェーダー言語であるHLSLには文字列出力の概念がなく、「Hello World」に相当するのは画面に何らかの色を出力する最小のピクセルシェーダーである。以下は画面全体を赤色で塗りつぶすピクセルシェーダーの例。

```hlsl
float4 main() : SV_Target
{
    return float4(1.0, 0.0, 0.0, 1.0); // 赤色を出力
}
```
