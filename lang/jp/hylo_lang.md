# Hylo

- 登場年: 2021年
- 設計者: Dave Abrahams, Dimi Racordon
- パラダイム: generic, systems, functional
- 系統: c-family

## 解決したかった課題

システムプログラミングでは、安全性とパフォーマンスを両立させるためにRustのような借用チェッカーが広く用いられてきたが、その学習コストの高さやエイリアシング制約の複雑さが課題視されていた。Hylo(旧称Val)は、参照ではなく値そのものの意味論(mutable value semantics)を核とすることで、借用チェッカーを使わずにメモリ安全性と高速性を両立させることを狙って設計された。Dave AbrahamsやDimi Racordonらが中心となり、Swiftのサブスクリプトの仕組み、C++のSTLに見られる汎用プログラミングの知見、Rustの借用の概念を参考にしている。双方向連結リストのように従来は参照セマンティクスでしか安全に書けなかったデータ構造も、値セマンティクスによって安全かつ高速に実装できることを目指している。

## 特徴

- 「値意味論(mutable value semantics)」を核とし、参照ではなく値そのものの受け渡し・変更としてプログラムを記述する
- 借用チェッカーを使わずに、メモリ安全性と実行速度の両立を狙う
- Swiftのサブスクリプトに着想を得た仕組みにより、値セマンティクスを保ちながら効率的にデータへアクセスできる
- C++のSTLのような汎用プログラミング(ジェネリクス)の知見を取り入れている
- 双方向連結リストのように従来は参照セマンティクスでしか安全に書けなかったデータ構造も、値セマンティクスで安全かつ高速に実装できることを目指す
- 元はValという名称で開発されていた実験的言語である
