# INTERCAL

- 登場年: 1972年
- 設計者: Don Woods, James Lyon
- パラダイム: esoteric, procedural
- 系統: esoteric

## 解決したかった課題

INTERCALは、当時のFortranやCOBOLなど既存言語の設計上の「常識」をあえて全て裏返すというパロディ精神から作られた、最古の難解言語とされる作品である。単純な代入や明快な制御構造といった、良い言語設計の教科書的な原則を意図的に無視し、「なるべく実用性から遠い、書きにくく理解しにくい言語」を作ることそのものがジョークだった。命令に丁寧語(`PLEASE`)を挿入する義務や、一定確率で命令を無視する仕様など、真面目な言語設計への風刺が随所に込められている。

## 特徴

- 変数への代入は`←`に似た専用記号で行い、通常のイコール記号による代入という概念自体を否定する
- ループや条件分岐を意図的に持たず、代わりに`COME FROM`という制御構造を使うなど既存の常識を覆す
- 命令の前に`PLEASE`を付けないとコンパイラに叱られ、逆に付けすぎても「礼儀正しすぎる」と怒られる
- プログラムの一部が一定確率でランダムに無視される仕様が存在する
- エラーメッセージ自体がジョークとして作り込まれている

## 現在の位置づけ

esoteric(難解言語)として位置づけられ、実用目的では使われない。難解言語というジャンルそのものの起点とされ、後続の多くのジョーク言語が参照する古典的な原点として語り継がれている。

## Hello World

配列に文字コードを1つずつ代入し、それを読み出して出力するという回りくどい方法で「Hello, World!」を出力する、古くから伝わる定番プログラムである。

```
DO ,1 <- #13
PLEASE DO ,1 SUB #1 <- #238
DO ,1 SUB #2 <- #108
DO ,1 SUB #3 <- #112
DO ,1 SUB #4 <- #0
DO ,1 SUB #5 <- #64
DO ,1 SUB #6 <- #194
DO ,1 SUB #7 <- #48
PLEASE DO ,1 SUB #8 <- #22
DO ,1 SUB #9 <- #248
DO ,1 SUB #10 <- #168
DO ,1 SUB #11 <- #24
DO ,1 SUB #12 <- #16
DO ,1 SUB #13 <- #162
PLEASE READ OUT ,1
PLEASE GIVE UP
```
