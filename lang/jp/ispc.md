# ISPC

- 登場年: 2011年
- 設計者: Matt Pharr, William R. Mark
- パラダイム: procedural, array, concurrent
- 系統: c-family

## 解決したかった課題

CPUのSIMD(ベクトル)命令を活用するには、従来はコンパイラの自動ベクトル化に頼るか、煩雑なSIMDイントリンシクスを手書きする必要があり生産性が低かった。IntelのMatt PharrらはLarrabeeプロジェクトでの経験から、GPUのSPMD(Single Program, Multiple Data)モデルをCPU向けに応用したプログラミングモデルを構想した。ISPCはC言語に似た文法でSPMDプログラムを記述し、コンパイラがそれをCPUのSIMDレーンへ自動的にマッピングすることで予測可能かつ高速なベクトル並列コードを実現する。ゲームエンジンやレンダラーなど、高性能なCPU並列処理が求められる分野で採用されている。

## 特徴

- C言語によく似た文法を採用しており、既存のCプログラマが習得しやすい
- `uniform`と`varying`という型修飾子でSIMDレーンごとに異なる値を持つデータと共通のデータを明示的に区別する
- GPUのSPMDプログラミングモデルをCPUのSIMD命令セット(SSE、AVXなど)に対応付け、プログラマが明示的にベクトル化コードを書かなくても高速な並列実行を得られる
- `foreach`文でSIMDレーンへの反復処理の割り当てを制御し、`task`によるマルチコア並列化も統合的に扱える
- コンパイラが生成コードの挙動を予測しやすい設計になっており、自動ベクトル化と異なり性能の見通しが立てやすい
- C/C++コードから直接呼び出し可能なオブジェクトファイルを生成し、既存のビルドシステムに統合しやすい

## 現在の位置づけ

現役の言語であり、Intelによって開発が継続されている。ゲームエンジンやレンダリングエンジンなど、CPU上での高性能なSIMD並列処理が求められる領域で実用的に利用されている。

## Hello World

ISPCにはデバッグ用の`print`文が用意されており、C言語に似た関数定義の中でメッセージを出力できる。

```c
export void hello() {
    print("Hello, world!\n");
}
```
