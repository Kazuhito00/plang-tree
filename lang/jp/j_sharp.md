# J#

- 登場年: 2002年
- 設計者: Microsoft
- パラダイム: object-oriented, procedural
- 系統: jvm-dotnet

## 解決したかった課題

Java言語やMicrosoft独自のJava実装であるVisual J++で開発してきたプログラマが、既存のコードやスキルを活かしたまま.NET Frameworkへ移行できるようにする橋渡しの言語が必要だった。Microsoftはハイデラバードのマイクロソフト インディア開発センターにおいて、Java・C#・Visual J++の影響を受けたVisual J#(通称J#)を開発し、2002年7月1日に発表した。

## 特徴

- Javaのバイトコードではなく.NET中間言語(IL)にコンパイルされる
- 既存のJavaバイトコードやソースコードを扱い、サードパーティのJavaライブラリからの移行を支援
- Javaとは異なり、C言語風のプリプロセッサ指令を使用できる
- 新しい.NET用の属性(attribute)、イベント、値型、デリゲートを定義することはできないという制限があった
- Visual Studio 2005以降のバージョンでは提供が終了した

## 現在の位置づけ

J#はMicrosoftによって開発中止となった過去の言語であり、2007年5月18日の最終リリース以降、マイクロソフトによる主要サポートは2012年に、延長サポートも2017年10月に終了した。現在では歴史的な.NET移行支援言語として位置づけられている。
