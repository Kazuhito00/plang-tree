# JADE

- 登場年: 1996年
- 設計者: Gilbert Simpson
- パラダイム: object-oriented
- 系統: domain-specific

## 解決したかった課題

1990年代半ば、ニュージーランドのJade Software社は、大規模な業務システムを開発・運用するにあたり、プログラミング言語・オブジェクト指向データベース・アプリケーションサーバー・IDEといった別々の製品を組み合わせて使うことの複雑さを解消したいと考えていた。

Gilbert Simpsonが構想したJADEは、Modula-2(さらにその起源であるPascal)に由来する構文を採用しつつ、言語処理系とオブジェクト指向データベース、アプリケーションサーバー、実行環境を一体化した「エンドツーエンド」の開発・運用プラットフォームとして1996年に最初にリリースされた。データベースサーバーからクライアントアプリケーションまでを単一の統合環境で扱えることが最大の特徴であった。

## 特徴

- オブジェクト指向のプログラミング言語と、オブジェクト指向データベース、アプリケーションサーバーを統合した単一プラットフォームである
- 構文はModula-2(その起源であるPascal)に由来する
- プロプライエタリ製品であり、Jade Software Corporationが単独で開発・提供している
- 開発ライセンスは無償だが、デプロイ(プロセス単位)には課金される二重ライセンス方式を採る
- 現在はWindowsのみをサポートし、以前提供していたLinux対応は打ち切られている

## 現在の位置づけ

JADEは現在も開発元のJade Software Corporationによって保守が続けられている現役のプロプライエタリなオブジェクト指向4GLである。2025年にもJADE 2025.0.01 (R1)がリリースされるなど、開発自体は継続している。

しかし対応プラットフォームはWindowsのみに絞られ、利用者もニュージーランドやオーストラリアなどの一部業務システムに限られており、世界的に見ると非常にニッチな存在である。
