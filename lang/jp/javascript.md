# JavaScript

- 登場年: 1995年
- 設計者: Brendan Eich
- パラダイム: scripting, functional, object-oriented, event-driven
- 系統: scripting

## 解決したかった課題

1995年、Netscape社はブラウザ戦争の最中にあり、静的なHTMLページにフォーム検証程度の簡単な動的挙動を持たせる軽量言語を至急必要としていた。Brendan Eichはわずか10日間でこの言語を設計・実装するという極めて短い期間の制約の中、Schemeの関数型の考え方とSelfのプロトタイプベースオブジェクトモデルを組み合わせ、Javaに似せた構文を与えることで採用を後押しした。この急造の経緯が、後年まで指摘される言語仕様上の癖にもつながっている。

## 特徴

- プロトタイプベースのオブジェクトモデル(ES6以降はクラス構文も併用可能)
- 関数を第一級の値として扱う関数型的な側面
- ブラウザのDOM操作とイベント駆動プログラミングを前提とした設計
- Node.jsの登場によりサーバサイド・CLIツールへも進出
- 動的型付けによる柔軟さと、型強制に起因する意外な挙動が共存

現在も「active」であり、ブラウザの標準言語としての地位は揺るがず、Node.jsによってサーバサイドや各種ツールチェーンにも広く浸透している。10日間で生まれた言語でありながら、世界で最も多く実行されているプログラミング言語の一つとなっている。
