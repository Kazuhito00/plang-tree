# JSFuck

- 登場年: 2012年
- 設計者: Martin Kleppe
- パラダイム: scripting
- 系統: esoteric

## 解決したかった課題

JSFuckは、JavaScriptの暗黙の型変換(type coercion)の柔軟性を極限まで利用し、`[ ] ( ) ! +`のわずか6文字だけで任意のJavaScriptコードを表現できることを示す目的で作られた。名称はBrainfuckに由来し、2009年のjjencodeなど既存の難読化手法の系譜を継承・発展させたものである。ブラウザのフィルタ回避やコード難読化、XSS攻撃ペイロードの生成といったセキュリティ分野での実用例がある一方、JavaScript仕様の奇妙さを浮き彫りにするジョーク的側面も強い。

## 特徴

- 使用できる文字が`[`, `]`, `(`, `)`, `!`, `+`の6種類のみという極端な制約を持つ
- 配列やブール値への暗黙の型変換を連鎖的に利用し、数値・文字列・任意の関数呼び出しをゼロから組み立てる
- 生成されるコードは元のJavaScriptに比べて桁違いに長くなり、人間が直接読み書きすることは事実上不可能
- 通常は専用のエンコーダで元のJavaScriptコードから自動変換して生成される
- ブラウザの文字種フィルタや構文チェックを回避する難読化・セキュリティペイロードとして実際に利用されている
- Brainfuckおよびjjencodeの系譜を継ぐ、難読化・難解言語のジョーク的伝統に位置づけられる

## Hello World

JSFuckは`[]()!+`の6文字だけで任意の値を組み立てる言語であるため、完全な「Hello, World!」相当のプログラムは通常のテキストエディタで手書きするには非現実的なほど長大(専用エンコーダで生成すると数千文字規模)になる。ここでは核となる仕組みを示す例として、数値の1を6文字だけで表現する式を示す。

```
+!+[]
```

これは、空配列`[]`を単項プラスで数値に変換すると`0`になり、`!+[]`(0の論理否定)が真偽値`true`になり、それをさらに単項プラスで数値変換することで`1`が得られる、という暗黙の型変換の連鎖を利用している。実際の「Hello, World!」出力は、この要領で各文字コードを1文字ずつ組み立てて連結することで実現される。
