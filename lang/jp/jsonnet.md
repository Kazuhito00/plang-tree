# Jsonnet

- 登場年: 2014年
- 設計者: Dave Cunningham
- パラダイム: declarative, functional, object-oriented
- 系統: domain-specific

## 解決したかった課題

Google社内では、サービスの設定を記述するJSON/YAMLファイルが肥大化し、環境ごとの微妙な違いを表現するために大量の重複したコピーが生まれ、保守性が著しく低下していた。Jsonnetは、JSONを拡張し、変数、関数、継承、ミックスインといったプログラミング言語的な機能を持ち込むことで、設定ファイルを体系的に生成・再利用できるようにすることを目指した。テンプレートエンジンではなく、JSONそのものを出力する純粋関数型の言語として設計された点が特徴である。

## 特徴

- 出力は常に有効なJSONであり、Jsonnetのコードはその生成過程を記述するテンプレート言語として機能する
- オブジェクトの継承(`+`によるオブジェクトのマージ)やミックスインにより、共通設定を再利用しつつ部分的に上書きできる
- 関数、ローカル変数、条件式などプログラミング言語的な機能を備えるが、副作用は持たない純粋関数型の評価モデルを採用している
- 「隠しフィールド」という概念により、最終的なJSON出力には含めない中間データを設定ファイル内に保持できる
- KubernetesのマニフェストやCI/CD設定など、大規模な構成管理の現場で採用されている

## 現在の位置づけ

特定分野で使われるニッチな言語である。Kubernetesを中心としたクラウドインフラの構成管理分野で、複雑な設定の再利用と生成を行うツールとして使われ続けている。

## Hello World

Jsonnetのプログラムはそれ自体が式であり、評価結果がそのままJSONとして出力される。

```jsonnet
{
  message: "Hello, World!"
}
```
