# Kuin

- 登場年: 2016年
- 設計者: くいなちゃん (Kuina-chan)
- パラダイム: procedural, object-oriented, functional
- 系統: scripting

## 解決したかった課題

日本のプログラマ「くいなちゃん」は、HSPのような手軽さを持ちながらC++のように実用的で高性能な言語がないという課題意識からKuinを開発した。ゲーム制作や実用アプリケーション開発を主な対象とし、初心者にも分かりやすい文法としつつ、静的型付けとクラスベースのオブジェクト指向機能を備えている。代入演算子に「::」を採用するなど、行の先頭に重要な情報が来るよう配慮した独自の構文設計を行っている。日本語話者を中心としたコミュニティで利用される、継続的に開発が続くゲーム・実用向け言語である。

## 特徴

- HSPのような手軽な学習曲線を保ちつつ、静的型付けとクラスベースのオブジェクト指向を備えた実用的な言語仕様
- 代入演算子に`::`を用いるなど、行頭に重要な情報(変数名など)が来るよう独自に設計された構文
- ゲーム制作を主な想定用途とし、標準ライブラリに描画・音声・入力などの機能を統合
- 手続き型・オブジェクト指向・関数型の複数パラダイムを組み合わせて利用できる
- 日本語話者中心のコミュニティ向けに、日本語のドキュメントや開発環境が整備されている

## 現在の位置づけ

ニッチな存在として位置づけられ、主に日本語話者を中心としたコミュニティでゲーム制作や趣味のプログラミングに利用されている。開発は継続的に行われており、実用と学習しやすさの両立を目指す言語として一定の支持を得ている。

## Hello World

`func main()`で始まるメイン関数の中で、CUIライブラリの`cui@print`関数を`do`文として呼び出し、文字列を出力する。

```
func main()
	do cui@print("Hello, World!\n")
end func
```
