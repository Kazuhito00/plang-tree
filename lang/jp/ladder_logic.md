# Ladder Logic

- 登場年: 1969年(最初のPLC「Modicon 084」の製造年。表記法自体の起源はリレー配線図の記録法であり、正確な初出年は一次資料上で確認できなかった)
- 設計者: Dick Morley(Modicon 084によるPLC実装), Odo Josef Struger(IEC 61131-3規格化を主導)。表記自体はリレー配線図の記録慣行から発展したもので、単一の考案者は一次資料上で確認できなかった
- パラダイム: rule-based, visual
- 系統: hardware-description

## 解決したかった課題

PLC(プログラマブルロジックコントローラ)が登場する以前、工場の自動化はリレーを多数組み合わせた配線盤によって実現されており、技術者はその配線を「リレー配線図」というグラフィカルな図面で記録・保守していた。

1968年、ゼネラルモーターズはハードワイヤードのリレー装置を電子的に置き換える提案を求め、その結果1969年に世界初のPLCとされる「Modicon 084」が開発された。このとき、現場の技術者や保守担当者が、FORTRANのような汎用プログラミング言語を新たに学ばなくてもソフトウェアを開発できるようにすることが動機とされた。そこで、リレー配線図と同じ見た目を持つグラフィカルな記法である「ラダーロジック」が、そのままPLCのプログラミング言語として採用された。

## 特徴

- 2本の縦の電源レール(母線)と、その間を横に結ぶ「ラング(段)」で構成されるグラフィカルな回路図的表記
- 接点(コンタクト)と呼ばれる論理判定要素と、コイルと呼ばれる出力(アクチュエータ)要素を組み合わせる
- AND・OR・NOTなどの二値論理演算を回路図の形で表現できる
- 手続き型言語というよりルールベース言語として捉えられる(条件が満たされたら出力が作動する、という規則の集合として動作する)
- 現在はIEC 61131-3規格の一部として、ストラクチャードテキストなど他のPLC言語と並んで標準化されている

## 現在の位置づけ

ラダーロジックは現在もPLCプログラミングにおいて最も広く使われている言語であり、IEC 61131-3規格に含まれる標準的なプログラミング言語の一つとして工業自動化の現場に深く根付いている。2019年のIEEE Spectrumによる人気プログラミング言語ランキングでは52言語中50位と低い順位だったが、これは汎用プログラミング言語との比較基準によるものであり、PLC制御という特定分野では今も主流の記法である。
