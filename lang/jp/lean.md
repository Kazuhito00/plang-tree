# Lean

- 登場年: 2013年
- 設計者: Leonardo de Moura
- パラダイム: functional, logic, declarative
- 系統: ml-functional

## 解決したかった課題

Leanは、数学の定理を厳密に形式化し、機械によって正しさを検証できる証明支援系として設計された。数学の証明は人間のレビューだけでは見落としが生じうる複雑なものになりつつあり、コンピュータによる形式検証が求められていた。Leonardo de Mouraは、依存型理論に基づく証明支援系を作ると同時に、その基盤となる型システムを実用的な依存型プログラミング言語としても使えるようにすることを目指した。証明を書く行為とプログラムを書く行為を同じ言語・同じ型システムの上で統一的に扱えることが、Leanの中心的なアイデアである。

## 特徴

- 依存型システムを備え、型そのものに値を含めることで極めて精密な仕様や証明を型として表現できる
- 定理証明支援系(Interactive Theorem Prover)として、証明を対話的に構築・検証できる
- tacticと呼ばれる証明戦略の記述機構を持ち、証明の自動化や再利用がしやすい
- 依存型プログラミング言語としても実用され、証明とプログラムを同一の言語で記述できる
- 数学ライブラリ(mathlibなど)のコミュニティが活発であり、大規模な形式化数学のプロジェクトを支えている

## 現在の位置づけ

現役で広く使われている。数学の形式化プロジェクトや定理証明の研究において主要な処理系の一つとして採用されており、数学者と計算機科学者の双方から活発に利用され続けている。

## Hello World

Leanのプログラムは`IO`モナドを介して標準出力に文字列を書き出す。

```lean
def main : IO Unit :=
  IO.println "Hello, World!"
```
