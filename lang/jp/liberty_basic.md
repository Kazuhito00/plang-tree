# Liberty BASIC

- 登場年: 1992年
- 設計者: Carl Gundel
- パラダイム: procedural, event-driven
- 系統: basic-family

## 解決したかった課題

プログラミング初心者やホビイストが、Windows上で動くGUIアプリケーションを、複雑なAPI呼び出しを意識することなく手軽に作れるようにしたいという課題があった。Liberty BASICは、使い慣れたシンプルなBASIC構文だけで、ウィンドウやボタンといったGUI要素を扱えるようにすることで、低い学習コストで実用的なWindowsアプリケーションを作成できる環境を提供することを目指した。

## 特徴

- シンプルなBASIC構文のままウィンドウ、ボタン、テキストボックスなどのGUI要素を扱える
- Windows APIの詳細を意識せずに、高水準な命令だけでGUIアプリケーションを構築できる
- インタプリタ方式で動作し、書いたコードをすぐに実行して確認できる
- イベント駆動型のプログラミングモデルにより、ユーザー操作に応じた処理を記述しやすい
- 実行ファイル(exe)への変換機能を備え、作成したプログラムを配布できる
