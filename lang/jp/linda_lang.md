# Linda

- 登場年: 1986年
- 設計者: David Gelernter
- パラダイム: concurrent, declarative
- 系統: concurrent-actor

## 解決したかった課題

1980年代、並列・分散計算が普及し始める中、プロセス間通信を簡潔かつ移植性高く記述する方法が求められていた。Gelernterは既存の並列言語が煩雑で扱いにくいと考え、計算そのものを記述する言語とは独立した「座標言語(coordination language)」としてLindaを設計した。共有の「タプル空間」にデータを出し入れする少数の操作(out, in, rd, evalなど)だけでプロセス同士を疎結合に連携させることを可能にした。この設計により、既存のホスト言語(C、Fortranなど)にLindaのモデルを組み込むだけで並列処理機能を追加できるようになった。

## 特徴

- プログラムそのものではなく、既存の言語に組み込んで使う「座標言語(coordination language)」として設計されている
- 共有された連想メモリ空間である「タプル空間(tuple space)」を介してプロセス間の通信と同期を行う
- `out`(タプルの生成)、`in`(取得と削除)、`rd`(参照のみ)、`eval`(非同期評価によるタプル生成)という少数の基本操作だけで並行処理を記述できる
- プロセス同士が時間的にも空間的にも直接結合せず、タプル空間を介して疎結合に連携できる
- C、Fortranなど既存のホスト言語にLindaのモデルを追加するだけで並列拡張が可能になる

## 現在の位置づけ

Lindaは特定の実用システムとして広く普及したわけではなく、現在はニッチな存在である。しかし、タプル空間による疎結合な並行処理モデルという発想は、JavaSpacesなど後続の分散コンピューティング技術の設計思想に影響を残しており、並行計算の理論的な議論では今も引き合いに出される。

## Hello World

Lindaはホスト言語(ここではC)に組み込む座標言語であるため、通常の出力はホスト言語の機能で行い、`out`によってタプル空間に完了を示すタプルを書き込む。

```c
main() {
    printf("Hello, world!\n");
    out("done");
}
```
