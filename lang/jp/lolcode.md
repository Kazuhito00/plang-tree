# LOLCODE

- 登場年: 2007年
- 設計者: Adam Lindsay
- パラダイム: esoteric, procedural
- 系統: esoteric

## 解決したかった課題

LOLCODEは、当時インターネットで流行していた「lolcat」ミーム(猫の画像に添えられる、わざと崩した英語の言い回し)をそのままプログラミング言語の構文にしてしまうというジョークから生まれた。「HAI」で始まり「KTHXBYE」で終わるプログラム、変数宣言が「I HAS A」になるといった構文は、ネットミームの言い回しを忠実にコードへ落とし込むこと自体が目的であり、生真面目な文法規則を持つ既存言語へのパロディでもある。

## 特徴

- プログラムの開始・終了がそれぞれ「HAI」「KTHXBYE」という挨拶・別れの言葉になっている
- 変数宣言は「I HAS A 変数名」、代入は「ITZ」など、lolcatミームの砕けた言い回しをそのまま構文にしている
- 条件分岐やループも「O RLY?」「IM IN YR ループ名」のようなミーム的表現で書く
- 出力命令が「VISIBLE」など、わざと崩した英語表現で統一されている
- 見た目はふざけているが、変数・条件分岐・ループを備えた実際に動くプログラミング言語である

## 影響を受けた言語

直接の言語的祖先は特定されていない。

## 現在の位置づけ

esoteric(難解言語)として位置づけられ、実用目的では使われない。インターネットミームをそのままプログラミング言語にした代表例として、難解言語入門としてもしばしば紹介される親しみやすい存在である。

## Hello World

「HAI」で始まり「KTHXBYE」で終わる、LOLCODEらしい定番の「Hello World」出力プログラムである。

```
HAI
CAN HAS STDIO?
VISIBLE "Hello World"
KTHXBYE
```
