# ML

- 登場年: 1973年
- 設計者: Robin Milner, Lockwood Morris, Malcolm Newey
- パラダイム: functional, procedural, generic
- 系統: ml-functional

## 解決したかった課題

ML(Meta Language)は、エディンバラ大学のRobin Milnerを中心に、Lockwood MorrisとMalcolm Neweyも加わって設計され、1973年に登場した。定理証明支援系LCF(Logic for Computable Functions)のためのメタ言語として、証明手続きを関数として記述する目的で開発された。

**注意: 本エントリはデータセット内の別エントリ「[Standard ML](standard_ml.md)」(1983年)とは明確に異なる言語である。** 英語版Wikipediaの記事には「Not to be confused with Standard ML」というハットノートが付されており、当初のMLは複数の方言に分裂していたが、それを統一しようとする動きが後に独立した標準化プロジェクトとなり、1983年にStandard MLとして結実した、という経緯が記事内で説明されている。日本語版Wikipediaも同様に「標準(ないし一方言)としてStandard ML (SML) があり」としており、MLとStandard MLを明確に区別している。

## 特徴

- 定理証明支援系LCFのための証明記述用メタ言語として開発された
- 型推論(静的・強い型付け)を特徴とする、関数型・汎用・命令型のマルチパラダイム言語
- ISWIM、POP-2、PAL、GEDANKENから影響を受けている(Infobox記載)
- Standard ML、OCaml、Haskellをはじめとする、後続のML系・関数型言語の直接の源流である

## 現在の位置づけ

MLは現在では歴史的言語として位置づけられている(status: historical)が、Standard ML・OCaml・Haskell・Scala・Rust・Kotlin・F#・Erlangなど、現代の主要言語の多くに直接的な影響を与えたことがWikipediaのInfoboxで明記されている、ML系・関数型言語群の源流である。
