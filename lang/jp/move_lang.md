# Move

- 登場年: 2019年
- 設計者: Sam Blackshear
- パラダイム: procedural, systems, generic
- 系統: c-family

## 解決したかった課題

Facebook(当時)が主導したブロックチェーンプロジェクトLibra/Diemでは、デジタル資産を扱うスマートコントラクトにおいて、資産の二重利用や誤った消失といったバグが繰り返し問題になっていた。Moveは、デジタル資産を「リソース」という特別な型として扱い、複製も暗黙の破棄もできないという制約を型システムのレベルで強制することで、こうしたバグを言語仕様そのものによって防止することを目指した。Solidityなどの既存のスマートコントラクト言語で発生していた資産管理上の脆弱性への、根本的な対処として設計された。

## 特徴

- 「リソース」型の値は自動的にコピーできず、明示的な移動(ムーブセマンティクス)によってのみ受け渡しできる
- リソースは必ずどこかの変数に所有され、暗黙に破棄されることがないよう型システムが保証する
- モジュールというまとまりでコードを整理し、リソースを操作できる関数を限定的に公開する設計を推奨する
- 静的な型検査とバイトコード検証により、実行前に多くの資産関連バグを検出できる
- ジェネリクス(総称型)をサポートし、様々な種類の資産に対して同じロジックを再利用できる

## 現在の位置づけ

現役で広く使われている。Libra/Diemプロジェクト自体は終了したが、Move言語はAptosやSuiといった新しいブロックチェーンプラットフォームに採用され、開発が継続されている。

## Hello World

Moveのモジュールでは、標準ライブラリの`debug`モジュールを使って文字列を出力する例が一般的である。

```move
module 0x1::HelloWorld {
    use std::debug;

    public fun hello() {
        debug::print(&b"Hello, World!");
    }
}
```
