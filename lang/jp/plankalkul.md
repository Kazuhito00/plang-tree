# Plankalkül

- 登場年: 1943年
- 設計者: Konrad Zuse
- パラダイム: procedural
- 系統: origin

## 解決したかった課題

コンラート・ツーゼは1930年代からリレー式計算機Z1〜Z3を開発する中で、機械語のビット列を直接操作するのではなく、チェスの局面評価や幾何学の定理証明といった複雑なアルゴリズムを記号的に記述したいと考えた。当時はプログラミング言語という概念自体が存在せず、計算手順は配線やスイッチ、あるいは機械固有の命令で表現するしかなかった。

ツーゼは変数・配列・条件分岐・繰り返しを備えた記法を単独で考案し、1945年頃までに「Plankalkül(計画計算)」としてまとめ上げた。戦時下・戦後の混乱で発表が遅れ、実装や普及には至らなかったが、構想自体は既存のどの言語よりも早く、当時のどの研究機関からも独立して生まれた点が特筆される。

## 特徴

- 配列や入れ子のレコード型を扱えるデータ構造を持つ、当時としては極めて先進的な設計
- 条件式や繰り返しなど構造化された制御構造を備えていた
- 2次元的な記法(値と添字を縦に並べる独特の表記)で表現された
- 浮動小数点数に相当する概念や、集合演算に近い操作も構想に含まれていた
- コンパイラや実行系は考案時には存在せず、あくまで紙上の設計にとどまった
- 考案から半世紀以上を経た1998年に、初めてソフトウェアエミュレータ上で実行された

## 現在の位置づけ

現在は歴史的資料としてのみ言及される言語であり(status: historical)、実用で使われることはない。

しかし設計年代の早さゆえに、プログラミング言語史の記述では必ず出発点として取り上げられる存在であり、1998年の実行成功は「世界最古のプログラミング言語が半世紀の時を経て動いた」出来事として広く報じられた。

## Hello World

Plankalkülには文字列出力という概念自体がほとんどなく、当時の設計では「画面に文字列を表示する」という発想が存在しなかった。そのため、この言語で書ける最も単純な例として、2つの8ビット値を加算するプログラムを示す。なお原記法は変数名とその添字を上下二段に並べる独特の二次元表記であり、以下は現代の文献でよく用いられる線形化した表記である。

```
P1 add (V0[:8.0], V1[:8.0]) → R0[:8.0]
V0[:8.0] + V1[:8.0] ⇒ R0[:8.0]
END
```
