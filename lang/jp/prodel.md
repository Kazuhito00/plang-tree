# プロデル

- 登場年: 2007年
- 設計者: ゆうと
- パラダイム: object-oriented, scripting
- 系統: scripting

## 解決したかった課題

日本語プログラミング言語TTSneoはVisual Basic 6.0をベースとしたスクリプト言語として親しまれていたが、.NET時代の到来とともに基盤技術が時代遅れになりつつあった。開発者「ゆうと」は、日本語の語順のままオブジェクト指向のWindowsアプリケーションを開発できる環境を、.NET Frameworkを基盤として作り直すことで、TTSneoユーザーが移行できる後継言語を提供したいと考えた。2007年8月にコンセプト版が公開された。

## 特徴

- 日本語の助詞を用いた構文解析により、自然な日本語の語順でプログラムを記述できる
- オブジェクト指向に対応し、GUI部品や画像描画など豊富な標準機能を持つ
- .NET Frameworkを基盤として動作し、Windows向けアプリケーション開発を主目的とする
- 2018年にはWebAssembly技術を用いたブラウザ実行環境「プロデル・オンライン」も公開された
- 現在も安定版・開発版の両方でバージョンアップが継続されている
