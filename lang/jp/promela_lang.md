# Promela

- 登場年: 1989年(推定。Promela自体の記事にInfobox/初出年の記載はなく、対のSPINモデル検査器の公開年に基づく推定値)
- 設計者: Gerard J. Holzmann
- パラダイム: declarative, concurrent
- 系統: logic-declarative

## 解決したかった課題

分散システムや並行プロトコルは、プロセス間の通信タイミングや同期の組み合わせが爆発的に増えるため、デッドロックや競合状態、想定外の受信といった欠陥を人手のテストだけで発見することが極めて難しい。Gerard J. Holzmannは、並行プロセスの振る舞いを簡潔にモデル化し、その正しさを網羅的に検証できる形式手法が必要だと考え、検証用のモデリング言語Promela(Process/Protocol Meta Language)を考案した。

Promelaで記述したモデルは、対になるSPINモデル検査器(Simple Promela INterpreter)によって解析される。SPINはモデルのランダム/反復的なシミュレーションを行うほか、状態空間全体を高速に網羅検証するCプログラムを生成することもできる。これにより、デッドロックの不在、想定外の受信、実行不能コードの有無、システム不変条件の正しさ、進行しない実行サイクルの有無、さらに線形時相論理(LTL)による性質を自動的に検証できる。

なお、Promela自体の記事にはInfoboxや明確な初出年の記載がなく、正確な年は一次資料上で確認できなかった。ここでは、対のSPINモデル検査器の英語版WikipediaのInfoboxに記載された公開年「1989年」を推定値として採用した(SPINは1980年から開発が始まり、1991年からフリーで公開されたとも記載されている)。

## 特徴

- bit、bool、byte、mtype、short、intといった基本データ型を持つ
- proctype宣言によるプロセス型の定義と、run文による動的なプロセス生成
- メッセージチャネルを介した同期(ランデブー、バッファ長0)または非同期(バッファ付き)の通信
- if/fi、do/odによるガード付き選択・反復の制御構造で、複数のガードが実行可能な場合は非決定的に選択される
- atomic構文により、一連の文を他プロセスとインターリーブされない不可分な単位として実行できる
- assert文によるシステム不変条件の検証、SPINモデル検査器と組み合わせた網羅的な状態空間検証
- ファイルは伝統的に拡張子.pmlで保存される

## 現在の位置づけ

Promelaは、Gerard J. Holzmannが考案した並行・分散システム検証用のモデリング言語であり、SPINモデル検査器の入力言語として、プロトコルや並行アルゴリズムの正しさを形式的に検証する目的で広く使われてきた。Isabelle/HOLで検証された実装がCAVAプロジェクトの一部として提供されるなど、形式手法の研究とも結びついている。

汎用プログラミング言語として使われることはなく、現在は主に学術研究やプロトコル・組込みシステムの形式検証といった専門的な文脈で使われる、ニッチな検証用言語という位置づけにある。

## Hello World

Promelaは検証対象のプロセスモデルを記述するための言語であり、標準出力に文字列を表示するという用途を主目的としていないため、Hello World的なプログラム例は一次資料上で確認できなかった。代わりに、記事に掲載されている最小のプロセス型定義の例を示す。

```promela
proctype A()
{
    byte state;
    state = 3;
}
```
