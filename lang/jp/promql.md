# PromQL

- 登場年: 2012年
- 設計者: Matt T. Proud, Julius Volz
- パラダイム: declarative, functional, query
- 系統: logic-declarative

## 解決したかった課題

SoundCloudでは、コンテナ化が進むインフラの監視に、StatsDやGraphiteといった既存の監視ツールでは対応しきれなくなっていた。多次元的なラベル付きメトリクスを収集し、それをリアルタイムに集計・アラート判定できる強力なクエリ言語が必要とされていた。Matt T. ProudとJulius Volzは、Googleの内部監視システムBorgmonの考え方を参考にしつつ、Prometheus向けに時系列データ専用の関数型クエリ言語としてPromQLを設計した。多次元データモデルと組み合わせることで、運用のシンプルさと強力な集計表現力を両立させている。

## 特徴

- ラベル(キー・バリューのペア)によって多次元的に識別される時系列データを扱う
- `rate()`、`sum()`、`avg()`、`histogram_quantile()`など豊富な集計・変換関数を備える
- 範囲ベクトル・瞬時ベクトル・スカラーといったデータ型を区別し、時間窓を指定した集計が行える
- アラートルールの条件式としてそのまま利用でき、監視と可視化の両方に使われる
- Prometheusのタイムシリーズデータベースに特化しており、他の汎用データには適用できない

## 現在の位置づけ

現在も現役の言語であり(status: active)、Prometheusを中核とするクラウドネイティブな監視エコシステムで、事実上の標準クエリ言語として広く使われ続けている。Kubernetes環境の監視・アラートにおいて特に重要な位置を占めている。

## Hello World

PromQLには文字列をそのまま出力する概念がないため、`label_replace`を使ってラベルにメッセージを埋め込むことで擬似的な「Hello World」を表現する。

```promql
label_replace(vector(1), "message", "Hello, World!", "", "")
```
