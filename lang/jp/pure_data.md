# Pure Data

- 登場年: 1996年
- 設計者: Miller Puckette
- パラダイム: visual, dataflow, event-driven
- 系統: educational-visual

## 解決したかった課題

商用ソフトウェアであるMaxを、オープンソースかつ無償で、より自由に拡張できる形で再設計したいという課題があった。Pure Dataは、Max/MSPの開発者でもあるMiller Puckette自身の手によって、そのアーキテクチャを整理し直しつつ生み出された。さらに、ネットワークを介して離れた場所にいる複数の演奏者がリアルタイムに音楽を共同制作できるようにするという、より発展的な目標も掲げられていた。

## 特徴

- オブジェクトをパッチコードで接続するビジュアルなデータフロー言語であり、Max/MSPと概念的に近い構造を持つ
- オープンソースかつ無償で提供され、誰でも自由に拡張・改変できる
- リアルタイムの音声・映像信号処理をグラフィカルなパッチとして組み立てられる
- ネットワーク越しの通信機能を備え、複数の場所をまたいだ共同パフォーマンスにも対応する
- 外部ライブラリ(externals)による拡張が容易で、独自のオブジェクトをC言語などで実装して追加できる

## 現在の位置づけ

現役で使われている言語であり、電子音楽制作、メディアアート、教育の場で広く利用され続けている。オープンソースであることから、研究者やアーティストによる独自拡張の基盤としても重宝されている。

## Hello World

Pure Dataもビジュアルなパッチとして構築される言語であり、メッセージボックスに文字列を格納し、それをコンソール出力用のオブジェクトへ接続することで「Hello, World!」を表示する。

```
[message: Hello, World!] --> [print]
```
