# Python

- 登場年: 1991年
- 設計者: Guido van Rossum
- パラダイム: object-oriented, procedural, functional
- 系統: scripting

## 解決したかった課題

Guido van Rossumは教育用言語ABCの開発に携わっていたが、ABCは読みやすい一方でモジュール化や例外処理といった実務向けの拡張性に欠けていた。1980年代末、研究機関でシステム管理やツール開発を行う中で、初心者にも読める簡潔な文法を保ちながら、実際のソフトウェア開発に耐える汎用性を持つ言語が必要だと考えた。インデントによるブロック構造の強制など、可読性を言語仕様そのものに組み込む設計を選んだ。

## 特徴

- インデントで構造を表す、可読性を最優先した構文
- 「Pythonic」と呼ばれる明確で一貫したコーディング文化
- 標準ライブラリと豊富なサードパーティパッケージ(pip)によるエコシステム
- 動的型付けながら型ヒントによる静的検査も併用可能
- 機械学習・データサイエンス分野での事実上の標準ライブラリ群(NumPy, PyTorch等)

## 現在の位置づけ

可読性重視の設計哲学が功を奏し、教育・Web開発・科学計算・機械学習など幅広い分野で現在も現役かつ最も広く使われる言語の一つである。特にAI・データサイエンス領域での存在感は圧倒的で、今後も中心的な地位を維持すると見られる。
