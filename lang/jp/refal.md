# REFAL

- 登場年: 1968年
- 設計者: Valentin Turchin
- パラダイム: functional, pattern-matching, symbolic
- 系統: ml-functional

## 解決したかった課題

1960年代のソ連では、文字列やリスト構造を扱う記号計算(自然言語処理や数式処理、プログラム変換など)を、数学的に単純明快でありながら大規模なプログラム作成にも実用的な言語で行いたいという要求があった。Valentin Turchinは、Lispのリスト指向とは異なる、パターンマッチと項書き換え(term rewriting)に基づく関数型言語Refalを設計し、木構造データの変換を自然に表現できるようにした。以降Refal-2、Refal-5などの実装が作られ、記号処理研究やプログラム変換理論の分野で使われ続けている。

## 特徴

- プログラムは一連の書き換え規則(パターン→式)として記述され、入力式にパターンがマッチすると対応する式へ置き換えられる
- Lispのリストに代わり、木構造をなす「式」がデータの基本単位であり、パターンマッチによってその構造を直接分解・構築できる
- 関数呼び出しの概念を持たず、すべての計算が項書き換えの繰り返しとして進行する
- 変数の型はなく、記号(アトム)と入れ子構造だけでデータを表現するシンプルなモデルを採用している
- プログラム変換やメタプログラミングの研究(超コンパイル: supercompilationの起源)に用いられてきた

## 現在の位置づけ

REFALはniche(ニッチ)な言語として位置づけられ、実務での利用はごく限られている。一方でTurchinが提唱した「超コンパイル(supercompilation)」というプログラム変換理論の起点として、プログラム最適化・変換研究の分野で今なお学術的な関心を集めている。

## Hello World

Refalではプログラムのエントリポイントを`$ENTRY`で宣言し、組み込み関数`Prout`で文字列を出力する。

```
$ENTRY Go {
  = <Prout 'Hello, world!'>;
}
```
