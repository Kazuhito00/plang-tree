# S-Lang

- 登場年: 1992年
- 設計者: John E. Davis
- パラダイム: scripting, procedural, object-oriented, array
- 系統: scripting

## 解決したかった課題

1992年、物理学者John E. Davisは、自身が開発していたテキストエディタ用に書いた関数群を他のプログラムでも再利用できるようにしたいと考え、S-Langライブラリの開発を開始した。当初のインタプリタの構文はPostScriptに似た構文だったが、後にC言語に近い構文へと進化し、オブジェクト指向的な構文要素も追加された。Davisの物理学・科学計算への関心を反映して、MATLABやIDLに似たベクトル化された配列演算がネイティブにサポートされている点も特徴である。

目的は、単体で動くインタプリタというより、テキストエディタ(JEDエディタが最初の採用例)のような既存アプリケーションに組み込んで拡張性を持たせるための、軽量で組込み可能なスクリプト言語ライブラリを提供することだった。

## 特徴

- 当初はPostScript風の構文だったが、後にC言語に近い構文へ進化した
- オブジェクト指向的な構文要素をサポート
- MATLABやIDLに似たベクトル化された配列演算をネイティブにサポート
- テキストエディタなど既存アプリケーションへの組み込みを前提に設計された(バージョン2.0以前は単体プログラムとして動作しなかった)
- JEDテキストエディタが最初にS-Langインタプリタを採用した
- バージョン2.0以降はUTF-8をサポート

## 現在の位置づけ

S-Langは現在も開発が続けられており(2022年8月にバージョン2.3.3をリリース)、GPL 2.0以降でライセンスされている。JEDテキストエディタをはじめ、天文学分野のソフトウェア(slsh、ISISなど)に組み込まれる形でnicheに使われ続けている。
