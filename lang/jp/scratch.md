# Scratch

- 登場年: 2003年
- 設計者: MIT Media Lab(Mitchel Resnickら)
- パラダイム: educational, visual, event-driven
- 系統: educational-visual

## 解決したかった課題

従来のテキストベースのプログラミング教育は、子供にとって文法エラー(タイプミスやセミコロンの付け忘れなど)が大きな障壁となり、本来学ぶべきプログラムの考え方に集中しづらいという問題があった。

MIT Media LabのMitchel Resnickらは、Logoのタートルグラフィックスの教育的発想を受け継ぎつつ、コードを文字で書く代わりにブロックをドラッグ&ドロップで組み合わせるだけでプログラムを作れる環境を目指し、Scratchを開発した。世界中の子供が創造的な作品作りを通じてプログラミングを学べることを狙いとしている。

## 特徴

- 命令や制御構造がジグソーパズルのようなブロックとして視覚的に表現される
- ブロックの形状によって文法的に組み合わせ可能な箇所が制限され、構文エラーが原理的に起きにくい
- スプライト(キャラクター)を動かしたりイベントに反応させたりするイベント駆動型の記述が中心
- 作品(プロジェクト)をオンラインコミュニティで共有・改変し合える仕組みを持つ
- アニメーションやゲーム、対話型アートなど幅広い創作活動に応用できる
- 世界中の学校教育やプログラミング入門教材として広く採用されている

## 現在の位置づけ

Scratchはブロックを組み合わせる視覚的プログラミング教育の世界的標準として定着しており、初等・中等教育のプログラミング学習教材として現在も広く使われ続けている。

文法エラーに悩まされずプログラムの概念を学べるという設計思想は、プログラミング教育のあり方そのものに大きな影響を与えた。

## Hello World

Scratchはブロックを組み合わせて記述するビジュアル言語のため、テキストコードの代わりに用いるブロックの構成を擬似コードとして示す。

```
[緑の旗が押されたとき] ハットブロックの下に
[「Hello, World!」と言う] ブロックをつなげる
```
