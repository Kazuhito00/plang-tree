# SequenceL

- 登場年: 1989年
- 設計者: Daniel Cooke, Nelson Rushton, Brad Nemanich
- パラダイム: functional, declarative, array
- 系統: ml-functional

## 解決したかった課題

SequenceLは1989年、テキサス工科大学でNASAの資金提供を受け、Daniel Cooke、Nelson Rushton、Brad Nemanichらによって開発が始められた。NASAが求めていたのは、要求仕様そのものが「自己検証可能」であるような仕様記述言語、つまり書かれた仕様をそのまま実行し、その結果を望ましい振る舞いと直接比較できるような言語だった。開発は20年以上にわたり継続され、後にTexas Multicore Technologies社によって商用のマルチコア対応コンパイラとして製品化された。

SequenceLの核となる「正規化-転置(normalize-transpose, NT)」という意味論は、スカラー値に対する演算をシーケンス(配列)の各要素に自動的に分配することで、プログラマが並列化を意識せずに書いたコードから、マルチコアCPUの処理能力を自動的に引き出すことを目指すものである。

## 特徴

- 「正規化-転置(NT)」意味論により、スカラー演算をシーケンスの各要素に自動分配し、明示的な指示なしにマルチコア並列化を行う自動並列化コンパイラ
- 静的型付け・型推論を備えた純粋関数型・宣言型言語
- 実行可能な仕様記述("self-verifying"な要求仕様)を目的としてNASAの資金で開発された
- マルチスレッドC++やOpenCLコードへのコンパイルが可能
- 20以上の言語と連携できる相互運用性
- コミュニティ版(無償)と商用版が存在する

## 現在の位置づけ

SequenceLは静的型付けかつ型推論を持つ純粋関数型・宣言型言語であり、マルチスレッドのC++やOpenCLコードへコンパイルされ、20以上の言語と連携可能である。バージョン3が2017年1月にリリースされ、コミュニティ版は無償で提供されているが、商用ライセンスの製品としてniche(専門分野向け)な用途で使われている。
