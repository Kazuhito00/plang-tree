# Short Code

- 登場年: 1950年
- 設計者: John Mauchly, William F. Schmitt
- パラダイム: procedural
- 系統: origin

## 解決したかった課題

1940年代後半、ENIACやBINAC、UNIVAC Iといった初期の電子計算機を動かすには、プログラマが機械語やごく低レベルなオペコードを直接手で書く必要があり、数式一つを計算させるだけでも煩雑な作業を要した。

ENIACの共同開発者であるJohn Mauchlyは、1949年に「Brief Code」という構想を発表し、機械語ではなく数式に近い記法で計算を記述できるようにすることを提案した。この構想はWilliam F. Schmittによって実装され、1949年にBINAC上で、続いて1950年にUNIVAC I上で動作するインタプリタとして完成し、「Short Code」と改称された。1952年にはA. B. TonikとJ. R. Loganによる改訂版がUNIVAC II向けに作られている。

目的は、機械語を意識せずに数式や条件分岐を人間が読み書きしやすい記法で表現し、それをインタプリタが逐次解釈して実行できるようにすることだった。

## 特徴

- 数式の各要素を2文字のコードで表現し、UNIVACの12バイトワードに合わせて6要素ずつまとめて格納する
- コンパイラではなくインタプリタ方式で、ソースを都度解釈しながら実行する(機械語の約50倍遅かったとされる)
- 四則演算や関数呼び出し、条件分岐に相当する記述をサポート
- 世界最初期の高水準言語の一つとして、プログラミング言語史の出発点に位置づけられる
- 実用性よりも数式的な記述の容易さを優先した設計

## 現在の位置づけ

Short Codeは現在は完全に歴史的な言語であり、実務で使われることはない。しかし、機械語を離れて数式的な記法でプログラムを記述するという発想を最初に実用化した言語として、後続の高水準言語開発の思想的な出発点の一つとなった。プログラミング言語史における「原点」として位置づけられる。

## Hello World

Short Codeは出力(コンソール表示)という概念を持たない数式評価インタプリタであり、現代的な意味での「Hello World」に相当するプログラム例は一次資料上確認できなかった。文献では、`a = (b + c) / b * c` のような算術式を2文字コードに変換して実行した例が紹介されている。
