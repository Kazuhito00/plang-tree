# SIGNAL

- 登場年: 1982年
- 設計者: Paul Le Guernic, Albert Benveniste, Thierry Gautier
- パラダイム: dataflow, declarative, concurrent
- 系統: hardware-description

## 解決したかった課題

1980年代初頭、信号処理システムの記述という課題に対し、P. Le Guernic、A. Benveniste、T. Gautierらは、フランスのIRISA/INRIAにおいて、同期データフローに基づく言語SIGNALの設計を開始した。最初の論文は1982年に発表され、言語の完全な記述はT. Gautierの博士論文として提示された。

SIGNALはEsterelやLustreとほぼ同時期に開発された「姉妹言語」であるが、単一のクロック(制御の同期)を前提とするEsterelやLustreの初期実装とは異なり、SIGNALは複数の独立したクロックを扱う「多クロック(polychronous)」なシステムを、関係(リレーション)に基づく仕様として記述できる点に特徴があった。これにより部分的な仕様や非決定的な仕様も扱うことができ、仕様から実装へ、同期系から非同期系へという段階的な設計手法を支えることを目指した。

## 特徴

- 同期データフロー(信号+同期)に基づき、プロセスを基本フローに関する方程式の集合として記述
- 複数の独立したクロックを扱う「多クロック(polychronous)」システムの記述が可能
- 関係(リレーション)に基づく仕様記述により、部分的・非決定的な仕様も表現できる
- ブロックダイアグラム的な配列・スライディングウィンドウ演算子を提供
- 仕様から実装まで、同期系から非同期系までを段階的に設計する方法論をサポート
- Polychronyツール群(バッチコンパイラ・GUIエディタ・形式検証ツールSigali)により現在も開発・利用されている

## 現在の位置づけ

SIGNALは現在、INRIAのEspressoチームが保守するオープンソースツール群Polychrony(バッチコンパイラ、GUIエディタ、形式検証ツールSigaliを含む)の中核言語として、nicheな研究・開発分野で使われ続けている。EsterelやLustreとともに「同期言語」というジャンルを切り開いた言語の一つであり、これら3言語の間で一方が他方に直接影響を与えたと明記する一次資料は確認できなかったが、同時代に同じ問題意識(反応システムの厳密な記述と検証)を共有して並行開発された点で深い関連がある。
