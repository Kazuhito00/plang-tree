# SISAL

- 登場年: 1983年
- 設計者: James McGraw
- パラダイム: functional, dataflow, array
- 系統: numeric-scientific

## 解決したかった課題

1980年代初頭、科学技術計算では複数プロセッサを持つ並列計算機が普及し始めたが、FortranやCのような命令型言語ではロックや同期を伴う並列プログラミングの記述・デバッグが難しかった。ローレンス・リバモア国立研究所やマンチェスター大学などの共同チームは、単一代入(single assignment)とデータフローの原理に基づく関数型言語SISALを設計し、副作用を排除することでコンパイラが自動的かつ安全に並列化できるようにした。前身のVALに再帰と有限ストリームを追加し、Fortranに匹敵する実行性能を目指した。

## 特徴

- すべての変数が一度しか値を束縛されない単一代入(single assignment)の原則に基づいている
- データフローグラフとしてプログラムを解析でき、データの依存関係だけから自動的に並列実行可能な箇所を検出できる
- 副作用を持たない純粋な関数型言語であり、ループもforall式などの副作用のない構文で表現される
- 配列演算を第一級でサポートし、科学技術計算に必要な数値処理を効率的に記述できる
- 前身言語VALに再帰呼び出しと有限ストリームを追加拡張したものである
- 逐次的なFortranコードに匹敵する実行性能を目指して設計された

## 現在の位置づけ

SISALはhistorical(歴史的役割を終えた)言語として位置づけられ、現在新規に採用されることはほとんどない。しかし単一代入・データフロー原理に基づく自動並列化という発想は、後の並列・関数型言語研究における重要な先駆例として参照され続けている。

## Hello World

SISALには明示的な`print`文がなく、`main`関数の返り値がプログラムの出力となる。

```
function main returns array[character]
  "Hello, world!"
end function
```
