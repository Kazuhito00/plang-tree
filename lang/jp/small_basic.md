# Small Basic

- 登場年: 2008年
- 設計者: Vijaye Raji, Microsoft
- パラダイム: procedural, event-driven
- 系統: educational-visual

## 解決したかった課題

Scratchのようなビジュアルプログラミングからテキストベースのプログラミングへとステップアップしようとする子供や初学者に、無理なく学べる入り口を用意したいという課題があった。Small Basicは、扱うキーワードの数を極限まで絞り込み(標準で14個程度)、シンプルなIDEと組み合わせることで、初学者が構文の複雑さに挫折することなくプログラミングの基礎概念を学べるように設計された。Microsoftによる教育目的のプロジェクトとして開発された。

## 特徴

- 使用するキーワードを14個程度にまで絞り込んだ、極めてシンプルな文法を持つ
- タートルグラフィックスやGraphicsWindowなど、視覚的なフィードバックが得やすいオブジェクトを標準で提供する
- インテリセンス(入力補完)を備えた専用の軽量IDEが用意されており、初学者でも迷わずコードを書ける
- イベント駆動型のプログラミングモデルにより、マウスやキーボード操作への応答処理を書きやすい
- 習得後はVisual Basicなど、より本格的な言語へスムーズに移行できるよう設計されている
