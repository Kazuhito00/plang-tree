# Tcl

- 登場年: 1988年
- 設計者: John Ousterhout
- パラダイム: scripting
- 系統: scripting

## 解決したかった課題

1980年代、John Ousterhoutはカリフォルニア大学バークレー校でチップ設計ツールなどの開発に携わる中で、様々な自作アプリケーションにそれぞれ独自の設定言語やコマンド言語を作り込む非効率さに気づいた。そこで、どんなアプリケーションにも組み込める汎用的で軽量なコマンド言語(Tool Command Language)を一度作れば、個別のアプリケーションごとに言語を再発明する必要がなくなると考えた。全てを文字列として扱うシンプルな構文により、C言語で書かれたアプリケーションへの組み込みを容易にした。

## 特徴

- 「すべての値は文字列」という統一的なデータモデル
- Cアプリケーションへの組み込みを前提としたシンプルなインタプリタ設計
- GUIツールキットTkと組み合わせた「Tcl/Tk」でクロスプラットフォームGUIを構築可能
- コマンドの並びとして構文を捉える一貫したコマンド指向の文法
- ネットワーク機器やEDA(電子設計自動化)ツールの設定言語として根強い採用

## 現在の位置づけ

現在は「niche」な位置づけで、かつてほどの広い採用は見られないものの、EDAツールやネットワーク機器の設定、テスト自動化(Expect)などの分野では今も根強く使われている。GUIツールキットTkと結びついた歴史的な知名度は高い。
