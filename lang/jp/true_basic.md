# True BASIC

- 登場年: 1985年
- 設計者: John G. Kemeny, Thomas E. Kurtz
- パラダイム: procedural, array
- 系統: basic-family

## 解決したかった課題

True BASICは、BASIC言語の生みの親であるJohn KemenyとThomas Kurtzが、Microsoft BASIC系の方言が乱立する状況に対抗し、構造化プログラミングの概念とANSI標準BASICを普及させるために開発した言語である。行番号やGOTO文に依存しない構造化された記述を可能にしつつ、既存のBASICとの親和性も維持した。行列演算のネイティブサポートや、再帰を可能にするローカル変数など、教育・科学技術計算向けの機能を備えていた。ハードウェアに依存しない設計により、異なる機種間でのコードの可搬性を確保することも目指された。

## 特徴

- GOTO文や行番号への依存を排し、DO/LOOPやSELECT CASEなどの構造化された制御構文を導入している
- 行列(配列)演算をネイティブにサポートし、MAT命令で行列の加減乗算などを直接記述できる
- 関数やサブルーチンにローカル変数を持たせることができ、再帰呼び出しにも対応する
- ANSI標準BASIC(ANSI X3.113)に準拠し、機種に依存しない移植性の高いコードを書ける設計になっている
- グラフィックス命令や科学技術計算向けの数学関数を豊富に備える
- 対話的な開発環境を提供し、教育機関や科学技術計算の現場での利用を意図していた

## 現在の位置づけ

True BASICは現在では実務でのプログラミング言語として使われることはほぼなくなり、歴史的役割を終えた言語として位置づけられる。構造化BASICの標準化を目指した設計思想は後年のBASIC処理系にも影響を与えたが、言語そのものは商用ソフトとしての展開が縮小し、教育・愛好家向けの利用にとどまっている。
