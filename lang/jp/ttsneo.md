# TTSneo

- 登場年: 2002年
- 設計者: ゆうと
- パラダイム: scripting, procedural
- 系統: scripting

## 解決したかった課題

2000年前後の日本では、プログラミング経験のないユーザーでも、日本語の語順に近い記述でWindows向けのソフトウェアを組み立てたいというニーズがあった。開発者「ゆうと」は、前身にあたる「TTS(Technology Terminal Script、2000年3月公開)」の設計をさらに発展させ、2002年5月に「TTSneo」として公開した。

TTSneoは、当時広く使われていたVisual Basic 6.0を実行基盤として採用することで、Visual Basicが持つ豊富なGUI部品や外部DLL・APIとの連携機能を、日本語に近い記述からそのまま呼び出せるようにした。これにより、テキストエディタや画像ビューアのような実用的なWindowsアプリケーションを、日本語の文章を書く感覚で開発できることを目指した。

## 特徴

- 命令を日本語の語順に近い形で記述できる、インタプリタ型のスクリプト言語
- 本体はVisual Basic 6.0で作成されており、Visual Basicが持つほとんどのGUI部品や外部DLL・APIをそのまま利用できる
- グラフィックス機能は日本語版Logo環境「ロゴライター」のソースコードを基調としており、図形描画を得意とする
- RAD(ラピッドアプリケーションデベロップメント)ツールを備え、画面部品を組み立てながらWindowsアプリケーションを開発できる
- 変数の事前宣言が不要で、文字列を中心とした柔軟なデータの扱いができる
- Windows 98~XP(Vista/7には一部対応)までを主な対象として動作する

## 現在の位置づけ

TTSneoは2016年2月にリリースされたバージョン1.94.2213を最後に、目立った更新が止まっている。開発者「ゆうと」自身が、.NET Framework基盤で文法を刷新した後継言語「プロデル」を2008年から公開したこともあり、実質的な開発の主軸はプロデルへと移った。

そのため現在のTTSneoは新規開発にはほとんど使われていないが、なでしこ・ドリトル・プロデルと並ぶ日本語プログラミング言語の草分けの一つとして、当時からのユーザーや日本語プログラミングの歴史を調べる人々の間で今も参照される、ニッチな存在であり続けている。

## Hello World

TTSneo自体の確認済みの一次資料(公式サイト・Wikipedia等)にHello World相当のサンプルコードは見当たらなかった。日本語の語順に近い記述で「表示する」といった命令を使っていたとされるが、具体的な構文を裏付ける出典は確認できていない。
