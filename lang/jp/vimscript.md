# Vim script

- 登場年: 1991年
- 設計者: Bram Moolenaar
- パラダイム: scripting, procedural
- 系統: shell

## 解決したかった課題

Vim scriptは、vi/exのコマンドライン言語をベースに、テキストエディタVimに組み込まれた形で発展したスクリプト言語である。初期のVimに制御構文(while等)や関数定義が追加されたことでプログラム的な自動化が可能になり、バージョン7でリストや連想配列といった高度なデータ構造が、バージョン8で無名関数(ラムダ)やmap()/filter()による関数型的な記述が追加された。なぜ最初にこの言語が作られたかという明確な設計動機についての記述はWikipedia上に見当たらなかったが、テキストエディタの操作をコマンドの組み合わせとして自動化・拡張したいという実用的な要求から、vi/exの機能を段階的に拡張する形で成立したことがうかがえる。

なお、Vim script単体としての「登場年」「設計者」はWikipedia上に明記がないため、Vimエディタ本体の初出年(1991年、Bram Moolenaar)を代用値として採用している。これは推定である点に留意されたい。

## 特徴

- vi/exのコマンドライン言語をベースとする
- 動的型付けの命令型(手続き型)スクリプト言語
- バージョン7以降、リスト・連想配列(辞書)などの高度なデータ構造をサポート
- バージョン8以降、無名関数(ラムダ)やmap()/filter()による関数型的な記述が可能
- ほとんどのVimプラグイン・拡張機能がVim scriptで書かれている
- クロスプラットフォーム対応、拡張子は`.vim`

## 現在の位置づけ
