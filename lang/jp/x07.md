# X07

- 登場年: 2026年
- 設計者: x07lang
- パラダイム: procedural, declarative
- 系統: ai-native

## 解決したかった課題

コード生成そのものは安価になった一方で、生成されたコードを信頼できるかどうかがボトルネックになっているという問題意識から、テキスト構文そのものを廃し、プログラムを標準化されたJSON形式の抽象構文木(AST)として直接編集・交換できる言語を作ろうとした。

## 特徴

- プログラムは正規化されたJSON AST(x07AST)として保存される
- 編集はRFC 6902 JSON Patch操作として行われる
- 診断情報(エラー等)は安定したJSON形式で提供され、修正案(quickfix)を機械的に適用できる
- `x07 ast to-text` / `x07 ast from-text`により、人間可読なテキスト形式と正規のJSON AST形式を相互変換できる
- 記憶安全なデフォルト・明示的な並行処理・世界(world)ベースの権限モデルを備える
