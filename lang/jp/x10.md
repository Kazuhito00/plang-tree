# X10

- 登場年: 2004年
- 設計者: Kemal Ebcioğlu, Vijay Saraswat, Vivek Sarkar
- パラダイム: object-oriented, concurrent, procedural
- 系統: numeric-scientific

## 解決したかった課題

X10は、DARPAのHigh Productivity Computing Systems(HPCS)構想のもとで、ペタスケール級の超並列計算機を高い生産性で扱えるプログラミングモデルを実現するためにIBMが開発した。従来の並列プログラミングは、性能を引き出すために低レベルな詳細を扱わねばならず、生産性の面で大きな障壁となっていた。そこでX10は、PGAS(分割グローバルアドレス空間)モデルを採用し、Java風のオブジェクト指向構文と組み合わせることで、非同期タスクや分散データを自然に記述できる言語を目指した。大規模並列計算機上でのプログラミングを、通常のオブジェクト指向言語に近い感覚で行えるようにすることを狙った。

## 特徴

- PGASモデルを採用し、複数の「プレイス」に分散したデータとタスクを、単一のプログラム内で統一的に扱える
- `async`/`finish`という構文により、非同期タスクの生成と完了待機を簡潔に記述できる
- Javaに似たオブジェクト指向構文を採用し、型安全性とジェネリクスを備えている
- 分散配列やイテレーション空間(region)を言語機能として持ち、データ並列処理を宣言的に記述できる
- IBMのメインフレームやスーパーコンピュータ環境をターゲットにした実装が提供された

## Hello World

X10ではJavaに似た構文で`Console.OUT.println`を用いて出力する。

```x10
class HelloWorld {
    public static def main(args: Rail[String]) {
        Console.OUT.println("Hello, World!");
    }
}
```
