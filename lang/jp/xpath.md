# XPath

- 登場年: 1999年
- 設計者: World Wide Web Consortium (W3C)
- パラダイム: query, declarative
- 系統: domain-specific

## 解決したかった課題

XMLが普及するにつれ、XML文書の木構造(要素・属性・テキストノードの階層)から、条件を指定して任意のノードを選び出す共通の記法が求められるようになった。当時、XSLTやXPointerといった複数の関連仕様がそれぞれ独自にノード参照の方法を定めようとしており、このままでは仕様間で似て非なる記法が乱立してしまう恐れがあった。W3Cは、これらの仕様が共通して使える単一のパス式言語を策定することで、XML文書内のノード選択という基本的な操作を統一しようとした。

## 特徴

- スラッシュで区切られたパス式によって、XML文書の木構造からノードを階層的にたどって選択できる
- 属性・親子関係・兄弟関係などを軸にした軸(axis)の概念により、柔軟なノードの相対的な位置指定が可能である
- 述語(条件式)を角括弧で指定でき、特定の条件を満たすノードだけを絞り込んで選択できる
- 文字列・数値・真偽値の操作を行う関数群を備え、単なるパス指定を超えた式評価ができる
- XSLTやXQuery、XML Schemaの一部など、XML関連の複数の仕様から共通して参照される基盤技術となっている

## 現在の位置づけ

active(現役で広く使われている言語)であり、XSLTやXQuery、各種プログラミング言語のXML処理ライブラリの内部で、XML文書内のノード選択のための標準的な手段として現在も広く使われている。

## Hello World

XPathは値を選択・評価するための式言語であり、単独で文字列を出力する概念はないが、文字列リテラルを評価する最小限の式は次のようになる。

```
"Hello, World!"
```
