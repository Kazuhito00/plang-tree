# XQuery

- 登場年: 2007年
- 設計者: W3C
- パラダイム: declarative, query
- 系統: logic-declarative

## 解決したかった課題

1990年代末から2000年代にかけてXMLは文書交換やデータ表現の標準フォーマットとして急速に普及したが、木構造を持つXML文書を検索・抽出・変換する統一的な手段が存在せず、開発者はXSLTやプログラミング言語による個別実装に頼らざるを得なかった。

W3Cは、リレーショナルDBに対するSQLのように、XML文書の集合に対して宣言的に問い合わせや変換を行える標準言語としてXQueryを策定し、階層構造を持つデータの検索・再構成を統一的に扱えるようにした。複数のXML文書やデータベースを横断した問い合わせを、単一の言語で表現できることも目標とされた。

## 特徴

- FLWOR式(For, Let, Where, Order by, Return)と呼ばれる構文でXMLデータを反復・抽出・整形する
- XPathを式言語の中核として内包し、XML木構造内のノードを経路表現で指定できる
- 問い合わせ結果として新たなXML文書を構築できる関数型的な性質を持つ
- 静的型付けのオプション機構を持ち、スキーマに基づく型検証が可能
- ネイティブXMLデータベースや一部のRDBMSのXML拡張機能で実装されている
- 名前空間やスキーマ検証など、XML特有の仕様を扱うための機能を一通り備える

## 現在の位置づけ

XQueryは現在ではニッチな位置づけにあり、JSON形式の普及によりXML自体の利用が相対的に縮小したこともあって主流にはならなかったが、一部のXMLネイティブデータベースやドキュメント処理システムでは今も利用されている。金融業界の取引メッセージ処理など、XMLが根強く使われる分野では現役の技術として残っている。
