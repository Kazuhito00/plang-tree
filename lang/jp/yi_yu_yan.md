# 易语言 (E Language)

- 登場年: 2000年
- 設計者: 吴涛 (Wu Tao)
- パラダイム: procedural, object-oriented, scripting
- 系統: scripting

## 解決したかった課題

中国語話者にとって、英語ベースのキーワードやプログラミング用語は学習の障壁となっていた。設計者の呉濤は「中国語でプログラムを書く」ことを実践するため、全ての構文・関数・キーワードを中国語で記述できる開発環境を目指した。Visual Basic的なビジュアル開発環境とライブラリ機構を取り入れ、初心者でも短期間でWindowsアプリを作れることを狙った。中国国内では教育・簡易業務アプリ開発で普及したが、海外では認知度が低く、マルウェア作成に悪用される事例も報告され評価は分かれている。

## 特徴

- 全てのキーワード・命令・関数名を中国語で記述でき、英語を知らなくてもプログラムが書ける
- Visual Basicに似たビジュアルフォームデザイナーを備え、GUI部品をドラッグ&ドロップで配置できる
- 「支持库(サポートライブラリ)」と呼ばれるモジュール機構によりAPIや機能を後から追加・拡張できる
- Windows APIを直接呼び出せる手続き型言語であり、コンパイルによりネイティブのexeファイルを生成する
- オブジェクト指向的なクラス定義もサポートし、簡易な業務アプリケーション開発に対応する
- 学習コストの低さから中国国内の初心者教育や簡易業務システムで使われる一方、マルウェア作成に悪用された事例も知られる
